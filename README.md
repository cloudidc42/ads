# สอนยิงแอด Facebook / TikTok Ads — หลักสูตรระดับโลก (Step 1–1000)

หลักสูตรยิงแอด Facebook Ads และ TikTok Ads แบบครบวงจร ตั้งแต่ระดับพื้นฐานที่สุด
จนถึงระดับมืออาชีพและระดับโลก สอนแบบ step-by-step ตั้งแต่ขั้นตอนที่ 1 ถึง 1000
แบ่งเป็น 100 Part เนื้อหาใช้งานได้จริง 100% แต่ละ Part มีความยาว 500–3000+ บรรทัด

## วิธีใช้หลักสูตรนี้

1. เริ่มจาก [`course/COURSE_OUTLINE.md`](./course/COURSE_OUTLINE.md) เพื่อดูภาพรวมหลักสูตรทั้งหมด
2. เรียนตามลำดับ Part 001 → Part 100 (แต่ละ Part ครอบคลุม 10 Steps)
3. ทำ Checklist และ Workshop ท้ายบทก่อนไป Part ถัดไป
4. ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ [`course/`](./course/) ตั้งชื่อไฟล์แบบ `part-XXX-ชื่อบท.md`
