# Part 010: สร้างและตั้งค่า Facebook Page ให้พร้อมขาย

**Section:** B — Facebook Ads Ecosystem Fundamentals
**Step ที่ครอบคลุม:** 91–100 (10 Steps)
**เวลาที่ใช้เรียนโดยประมาณ:** 5–6 ชั่วโมง (รวมลงมือสร้าง Page จริงและทำ Workshop)

Facebook Page คือ "หน้าร้าน" ของธุรกิจคุณบน Facebook และเป็นสิ่งที่ทุกโฆษณาต้องอ้างอิงถึงเสมอ ไม่ว่าคุณจะยิงแอดเก่งแค่ไหน ถ้า Page ดูไม่น่าเชื่อถือ ลูกค้าที่คลิกเข้ามาดูจะลังเลและปิดหน้าไปในไม่กี่วินาที Part นี้จะพาคุณสร้าง Page ตั้งแต่ศูนย์แบบมืออาชีพ พร้อมตั้งค่าทุกส่วนที่ส่งผลต่อ Conversion และความน่าเชื่อถือ

## Step 91: สร้าง Facebook Page ตั้งแต่ต้นแบบมืออาชีพ

### ขั้นตอนการสร้าง Page

1. เข้า Facebook ด้วย Personal Account ที่ปลอดภัย (ตั้งค่าตาม Part 006 แล้ว) ไปที่เมนู **Pages** ทางแถบซ้าย หรือเข้าตรงที่ `facebook.com/pages/create`
2. เลือก **Page Name** — ควรเป็นชื่อธุรกิจที่ตรงกับชื่อที่ลูกค้าค้นหาจริง ไม่ใช่ชื่อที่ยัด Keyword เยอะเกินไป (เช่น "ร้านกาแฟ Beanovation" ดีกว่า "กาแฟสด กาแฟอร่อย ร้านกาแฟใกล้ฉัน Beanovation คาเฟ่")
3. เลือก **Category** อย่างระมัดระวัง (รายละเอียดใน Step 92)
4. กรอกข้อมูลพื้นฐาน: คำอธิบายสั้น, เว็บไซต์, ข้อมูลติดต่อ
5. อัปโหลด Profile Picture และ Cover Photo (รายละเอียดใน Step 93)
6. เชื่อมต่อ WhatsApp/Instagram ถ้ามี (ไม่บังคับ แต่แนะนำให้ทำตั้งแต่ต้นถ้าใช้งานจริง)

### การตัดสินใจสำคัญที่ต้องคิดให้ดีตั้งแต่วันแรก

**1. ใครควรเป็นเจ้าของ Page (Admin คนแรก)?** — ควรเป็นบุคคลที่เกี่ยวข้องกับธุรกิจโดยตรงและมี Business Manager เป็นผู้ดูแลหลัก ไม่ควรให้ฟรีแลนซ์หรือเอเจนซี่สร้าง Page ด้วยบัญชีส่วนตัวของเขาแล้วเพิ่มคุณเป็นแค่ Editor เพราะถ้าเลิกงานกัน คุณอาจเสียสิทธิ์ Page ทั้งหมด **แนวทางที่ถูกต้องคือให้เจ้าของธุรกิจสร้าง Page เอง หรือสร้างผ่าน Business Manager ของธุรกิจตั้งแต่ต้น** แล้วค่อยให้สิทธิ์เอเจนซี่ผ่าน Partner Access (จะสอนใน Part 011)

**2. ชื่อ Page ควรคงที่ระยะยาว** — การเปลี่ยนชื่อ Page บ่อยๆ ทำให้เสีย History และอาจโดนระบบตรวจสอบเพิ่มเติม (Meta จำกัดจำนวนครั้งที่เปลี่ยนชื่อ Page ได้ในบางกรณี) ควรคิดชื่อให้รอบคอบตั้งแต่แรก

**3. หนึ่งธุรกิจ ควรมีกี่ Page?** — โดยหลักการคือ 1 แบรนด์ = 1 Page หลัก ถ้ามีหลายสาขา ให้ใช้ Page เดียวแล้วจัดการผ่าน Locations Feature (สำหรับธุรกิจที่มีหลายสาขาจริงๆ) ไม่ใช่สร้าง Page แยกทุกสาขาโดยไม่มีเหตุผล เพราะจะทำให้ Social Proof (Like, Review) กระจัดกระจายไม่รวมเป็นพลังเดียว

### ข้อผิดพลาดที่พบบ่อย

- สร้าง Page ด้วยบัญชี Personal ที่ไม่ปลอดภัย (ไม่มี 2FA) ทำให้เสี่ยงถูกแฮกทั้ง Page
- ใช้ชื่อ Page ที่มี Emoji หรือสัญลักษณ์แปลกๆ มากเกินไป ซึ่งอาจขัดนโยบายชื่อของ Meta และดูไม่น่าเชื่อถือ
- ไม่กรอกข้อมูลติดต่อให้ครบตั้งแต่ต้น ทำให้ลูกค้าที่เข้ามาดู Page ครั้งแรกไม่พบข้อมูลสำคัญและปิดหน้าไปเลย
- สร้าง Page ใหม่ทุกครั้งที่มีปัญหา (เช่น โดน Restrict) แทนที่จะแก้ปัญหาที่ต้นเหตุ ทำให้เสีย History และ Social Proof ที่สร้างมาทั้งหมด

### เปรียบเทียบวิธีสร้าง Page: ธุรกิจเดี่ยว vs เอเจนซี่ทำให้ลูกค้า

| สถานการณ์ | วิธีที่ถูกต้อง | ความเสี่ยงถ้าทำผิดวิธี |
|---|---|---|
| เจ้าของธุรกิจสร้างเอง | สร้างผ่าน Business Manager ของธุรกิจตั้งแต่ต้น | ต่ำ — ควบคุมทุกอย่างได้เต็มที่ |
| เอเจนซี่สร้างให้ลูกค้าใหม่ทั้งหมด | สร้าง Business Manager ในชื่อลูกค้า แล้วให้เอเจนซี่ขอ Partner Access | ปานกลาง — ต้องอธิบายขั้นตอนให้ลูกค้าเข้าใจก่อน |
| เอเจนซี่สร้าง Page ด้วยบัญชีตัวเองแล้วยกให้ลูกค้าทีหลัง | ไม่แนะนำ | สูงมาก — ลูกค้าอาจเสีย Page ทั้งหมดถ้าเลิกงานกันไม่ราบรื่น |
| รับช่วง Page ที่มีอยู่แล้วจากเจ้าของเดิม | ตรวจสอบ Page Roles และขอสิทธิ์ผ่านกระบวนการที่ถูกต้องจาก Admin ปัจจุบัน | ต่ำถ้าทำตามขั้นตอน — เสี่ยงสูงถ้าขอรหัสผ่านตรงจากเจ้าของแทนขอสิทธิ์ Role |

### กรอบเวลาที่แนะนำสำหรับการสร้าง Page ใหม่ก่อนเริ่มยิงแอด

ธุรกิจที่เพิ่งสร้าง Page ใหม่เอี่ยมและรีบยิงแอดทันทีในวันเดียวกันมีความเสี่ยงสูงกว่าธุรกิจที่ให้เวลา Page "อุ่นเครื่อง" สักระยะ แนวทางที่แนะนำคือ:

1. **สัปดาห์ที่ 1** — ตั้งค่า Page ให้ครบทุกส่วน โพสต์เนื้อหาจริงอย่างน้อย 5-10 โพสต์เพื่อให้ Page ดูมีกิจกรรม ไม่ใช่ Page เปล่าที่สร้างมาเพื่อยิงแอดอย่างเดียว
2. **สัปดาห์ที่ 2** — เริ่มเชิญเพื่อน/ลูกค้าเก่ามา Like Page เพื่อสร้าง Social Proof เริ่มต้น
3. **สัปดาห์ที่ 3 เป็นต้นไป** — เริ่มยิงแอดด้วยงบน้อยๆ ก่อน (Testing Budget) แล้วค่อยขยับขึ้นตาม Performance

แนวทางนี้ไม่ใช่กฎตายตัวของ Meta แต่เป็น Best Practice ที่นักยิงแอดมืออาชีพจำนวนมากใช้เพื่อลดความเสี่ยงจาก Account Trust Score ที่ยังต่ำในช่วงแรก (ตามที่อธิบายไว้ใน Part 009 Step 83)

## Step 92: เลือก Category และตั้งค่า About ให้ครบถ้วน

### ทำไม Category สำคัญกว่าที่คิด

Category ไม่ใช่แค่ Label สวยๆ แต่มีผลต่อ:

1. **ฟีเจอร์ที่ Page จะได้ใช้** — เช่น Page ประเภท "Restaurant" จะได้ฟีเจอร์เมนูอาหาร, การจอง (Reservations), Category "Local Business" จะได้แสดงเวลาเปิด-ปิด และแผนที่
2. **การตรวจสอบนโยบาย (Policy Scrutiny)** — Category บางประเภท เช่น "Health/Wellness", "Financial Service", "Alcohol" จะถูกจับตาจากระบบ AI Review เข้มงวดกว่าประเภททั่วไป ถ้าเลือก Category ผิดประเภทเพื่อ "หลีกเลี่ยง" การตรวจสอบ อาจทำให้ Page ถูกระบุว่าให้ข้อมูลเท็จซึ่งเสี่ยงกว่าเดิม
3. **Special Ad Category** — ถ้าธุรกิจของคุณอยู่ในกลุ่มที่อยู่, งาน, เครดิต, การเมือง ระบบอาจ Flag อัตโนมัติจาก Category ที่เลือก ซึ่งจะจำกัด Targeting บางอย่าง (รายละเอียดเพิ่มใน Part 020)

### วิธีเลือก Category ที่ถูกต้อง

ไปที่ **Page Settings > Page Info > Categories** สามารถเลือกได้สูงสุด 3 Category ควรเลือกให้ตรงกับธุรกิจจริงที่สุดเป็นอันดับแรก แล้วเพิ่ม Category รองที่เกี่ยวข้องเพื่อให้ค้นหาเจอง่ายขึ้น เช่น ร้านกาแฟที่ขายเบเกอรี่ด้วย อาจเลือก "Coffee Shop" เป็นหลัก และ "Bakery" เป็นรอง

### การกรอก About ให้ครบถ้วน

ส่วน About ควรกรอกครบทุกช่องที่เกี่ยวข้อง:

| ช่องข้อมูล | สิ่งที่ควรกรอก | เหตุผล |
|---|---|---|
| Description (คำอธิบายสั้น) | สรุปธุรกิจใน 1-2 ประโยค บอกจุดขายชัดเจน | แสดงในผลการค้นหาและ Preview ลิงก์ |
| Long Description | รายละเอียดธุรกิจ, ประวัติ, จุดเด่น | ช่วย SEO ภายใน Facebook และสร้างความน่าเชื่อถือ |
| Website | URL เว็บไซต์หลัก | เชื่อมโยงไปยัง Landing Page/ระบบขาย |
| Phone/Email | ข้อมูลติดต่อที่ Active จริง | ลูกค้าติดต่อได้ทันที ลดการเสียโอกาสขาย |
| Address | ที่อยู่จริงถ้ามีหน้าร้าน | สำคัญมากสำหรับธุรกิจที่ต้องการ Local Traffic |
| Business Hours | เวลาเปิด-ปิดจริง อัปเดตตามวันหยุด | ลดความสับสนของลูกค้า และมีผลต่อ Local Search |
| Price Range | ระดับราคาสินค้า/บริการ | ช่วยกรองลูกค้าที่ตรงกลุ่มเป้าหมายตั้งแต่แรกเห็น |

### ข้อผิดพลาดที่พบบ่อย

- เลือก Category ที่ไม่เกี่ยวข้องเพื่อหวังผลด้าน Targeting (เช่น เลือก "Public Figure" สำหรับ Page ขายสินค้า) ซึ่งอาจขัดนโยบายการให้ข้อมูลเท็จ
- กรอก Description ซ้ำกับ Long Description แบบ Copy-paste ทำให้ดูไม่เป็นมืออาชีพ
- ไม่อัปเดต Business Hours ตามเทศกาล ทำให้ลูกค้าไปหน้าร้านแล้วไม่พบว่าปิด
- ไม่กรอก Website ทำให้ Facebook ไม่สามารถ Suggest การเชื่อมต่อ Pixel/Domain ได้อัตโนมัติในบางเมนู

## Step 93: Profile Picture และ Cover Photo ที่ Convert

ภาพหน้า Page คือสิ่งแรกที่ลูกค้าเห็นก่อนตัดสินใจว่าจะเชื่อถือธุรกิจนี้หรือไม่ — เป็นเหมือน "หน้าปกร้าน" ในโลกออนไลน์

### Profile Picture

**ขนาดที่แนะนำ:** 170x170 พิกเซล (แสดงผลจริงบน Desktop) แต่ควรอัปโหลดไฟล์ต้นฉบับที่มีความละเอียดสูงกว่านั้นมาก (เช่น 500x500 พิกเซลขึ้นไป) เพื่อให้ภาพคมชัดในทุกอุปกรณ์ ไฟล์ต้องเป็นสัดส่วนสี่เหลี่ยมจัตุรัส (1:1)

**หลักการเลือกภาพ:**

- ธุรกิจที่มีโลโก้ชัดเจนอยู่แล้ว → ใช้โลโก้เวอร์ชันที่อ่านง่ายในขนาดเล็ก (หลีกเลี่ยงโลโก้ที่มีตัวอักษรเล็กมากจนอ่านไม่ออกตอนย่อ)
- ธุรกิจ Personal Brand (โค้ช, ที่ปรึกษา, ผู้เชี่ยวชาญ) → ใช้รูปหน้าตรงที่เห็นหน้าชัดเจน ยิ้ม ดูน่าเชื่อถือ ไม่ใช่รูปที่ถ่ายจากที่ไกลจนมองไม่เห็นหน้า
- หลีกเลี่ยงพื้นหลังที่รก มีข้อความเยอะเกินไป เพราะภาพจะแสดงในขนาดเล็กมากในหลายจุด (เช่น ข้าง Comment)

### Cover Photo

**ขนาดที่แนะนำ:** 820x312 พิกเซล บน Desktop (สัดส่วนประมาณ 2.63:1) แต่ต้องระวังว่าบนมือถือจะถูก Crop ต่างจาก Desktop มาก ควรออกแบบให้ข้อความ/องค์ประกอบสำคัญอยู่ **กึ่งกลางภาพ** ไม่ใช่ขอบภาพ เพื่อไม่ให้ถูกตัดหายไปตอนแสดงบนอุปกรณ์ที่ต่างกัน

**สิ่งที่ Cover Photo ควรสื่อสาร:**

1. Value Proposition หลักของธุรกิจ (ทำไมต้องเลือกเรา)
2. โปรโมชันปัจจุบัน (ถ้ามี) — แต่ต้องอัปเดตสม่ำเสมอ ไม่ใช้โปรที่หมดอายุแล้วค้างไว้
3. ภาพสินค้า/บริการจริงที่ดูน่าดึงดูด ไม่ใช่ภาพ Stock ที่ดูปลอม

**รูปแบบ Cover Photo ที่ Convert สูงตามประเภทธุรกิจ:**

| ประเภทธุรกิจ | แนวทาง Cover Photo |
|---|---|
| ร้านอาหาร/คาเฟ่ | ภาพอาหาร/เครื่องดื่มจานเด็ดถ่ายสวย พร้อมชื่อร้านและที่ตั้งสาขา |
| คลินิก/ความงาม | ภาพ Before-After (ถ้านโยบายอนุญาต) หรือภาพบรรยากาศคลินิกที่สะอาดน่าเชื่อถือ |
| คอร์สออนไลน์ | ภาพผู้สอนพร้อมข้อความสรุปผลลัพธ์ที่ผู้เรียนจะได้รับ |
| E-commerce | ภาพสินค้าขายดี Bestseller พร้อม Social Proof (ยอดขาย/รีวิว) |
| B2B/บริการมืออาชีพ | ภาพทีมงาน หรือ Infographic สรุปบริการหลัก |

### ข้อผิดพลาดที่พบบ่อย

- ใช้ภาพที่มีข้อความเยอะเกินไปจนอ่านไม่ทันตอนเลื่อนผ่าน
- ไม่อัปเดต Cover Photo เลยเป็นปี ทำให้ดูเหมือน Page ที่ไม่มีคนดูแล
- ใช้ภาพที่มีสัดส่วนไม่ตรงจนถูก Crop เพี้ยน (หน้าคนถูกตัดหัวตัดเท้า)
- ใช้ภาพ Stock Photo ที่ดูปลอมชัดเจน (คนต่างชาติยิ้มแบบไม่เป็นธรรมชาติ) ซึ่งลดความน่าเชื่อถือของธุรกิจไทย

## Step 94: ตั้งค่า Call-to-Action Button บนเพจ

ปุ่ม CTA บน Page คือจุดที่เปลี่ยน "คนเข้ามาดู" ให้กลายเป็น "คนที่เริ่ม Action" — ตั้งอยู่ใต้ Cover Photo และมองเห็นได้ทันทีที่เข้า Page

### วิธีตั้งค่า

ไปที่หน้า Page > คลิกปุ่ม **Add a Button** (หรือถ้ามีปุ่มอยู่แล้ว คลิกปุ่มนั้นแล้วเลือก **Edit Button**) จากนั้นเลือกประเภทปุ่มและปลายทาง

### ตัวเลือกปุ่มหลักและการเลือกให้ตรงกับ Funnel

| ปุ่ม CTA | ปลายทางที่เหมาะสม | เหมาะกับธุรกิจ |
|---|---|---|
| Shop Now / Shop on Website | ลิงก์ไปหน้าสินค้า/หน้าแรกเว็บไซต์ | E-commerce, ธุรกิจที่ขายผ่านเว็บ |
| Send Message | เปิด Messenger Chat | ธุรกิจที่ปิดการขายผ่านแชท (SME ส่วนใหญ่ในไทย) |
| Call Now | โทรออกทันทีจากมือถือ | ร้านอาหาร, คลินิก, บริการที่ต้องโทรจอง |
| Book Now | ลิงก์ระบบจองออนไลน์ | คลินิก, ร้านเสริมสวย, ที่พัก |
| Sign Up | ลิงก์หน้าลงทะเบียน/สมัครสมาชิก | คอร์สออนไลน์, สัมมนา, สมาชิก |
| Learn More | ลิงก์ Landing Page ข้อมูลเพิ่มเติม | ธุรกิจที่ต้องอธิบายก่อนตัดสินใจ (B2B, High-ticket) |
| WhatsApp | เปิดแชท WhatsApp | ธุรกิจที่มีลูกค้าต่างชาติ หรือทีมใช้ WhatsApp หลัก |

### หลักการเลือกปุ่มที่ถูกต้อง

**ปุ่ม CTA ต้องตรงกับ "Action เดียว" ที่คุณต้องการมากที่สุดในตอนนี้** ไม่ใช่เลือกตามความชอบ ถ้าธุรกิจของคุณปิดการขายผ่านแชทเป็นหลัก แต่ตั้งปุ่มเป็น "Shop Now" ไปเว็บไซต์ที่ยังไม่สมบูรณ์ คุณจะเสียโอกาสจากคนที่อยากคุยแชทแต่หาปุ่มแชทไม่เจอ (แม้ยังสามารถกด Message ผ่านไอคอนอื่นได้ แต่ Conversion Rate จะลดลงเพราะเพิ่ม Friction)

### ข้อผิดพลาดที่พบบ่อย

- ตั้งปุ่มแล้วไม่เคยอัปเดตแม้ธุรกิจเปลี่ยนโมเดล (เช่น เปิดเว็บไซต์ใหม่แล้วแต่ปุ่มยังลิงก์เว็บเก่าที่ปิดไปแล้ว)
- ใส่ลิงก์ที่ไม่มี UTM Parameter ทำให้วัดผลไม่ได้ว่า Traffic จากปุ่มนี้มาจากไหนและสร้าง Conversion เท่าไหร่
- ตั้งปุ่ม Call Now ทั้งที่ไม่มีคนรับโทรศัพท์นอกเวลางาน ทำให้ลูกค้าผิดหวังตอนโทรแล้วไม่มีคนรับ

## Step 95: Page Roles และการจัดการสิทธิ์ทีมงาน

การจัดการสิทธิ์ Page อย่างถูกต้องคือการป้องกันความเสี่ยงที่มองไม่เห็นแต่สร้างความเสียหายใหญ่ได้ในอนาคต

### ระดับสิทธิ์บน Page แบบดั้งเดิม (สำหรับ Page ที่ยังไม่ผ่าน Business Manager)

| Role | สิทธิ์ที่ทำได้ |
|---|---|
| Admin | ควบคุมทุกอย่างรวมถึงจัดการ Role อื่น, ลบ Page ได้ |
| Editor | แก้ไขเนื้อหา, ส่งข้อความ, สร้างโฆษณา แต่จัดการ Role ไม่ได้ |
| Moderator | ตอบข้อความ, Comment, ดู Insights แต่แก้ไขข้อมูล Page ไม่ได้ |
| Advertiser | สร้างโฆษณาและดู Insights แต่แก้ไขเนื้อหา Page ไม่ได้ |
| Analyst | ดู Insights เท่านั้น ไม่สามารถแก้ไขหรือโพสต์ได้ |
| Jobs Manager | จัดการประกาศงานบน Page (สำหรับธุรกิจที่ใช้ Jobs on Facebook) |
| Live Contributor | ไลฟ์สดผ่าน Page ได้ แต่ไม่มีสิทธิ์อื่นเพิ่มเติม |

หมายเหตุ: Meta ได้ปรับระบบให้ Page ที่ผูกกับ Business Manager ใช้ระบบ **Business Manager Roles** (Full Control / Partial Access กับ Task ที่เจาะจง) เป็นหลักมากขึ้น ซึ่งจะอธิบายละเอียดใน Part 011 — Step นี้เน้นหลักการพื้นฐานที่ต้องเข้าใจก่อน

### หลักการมอบสิทธิ์อย่างปลอดภัย

1. **ให้สิทธิ์เท่าที่จำเป็นเท่านั้น (Principle of Least Privilege)** — แอดมินที่ตอบแชทลูกค้าไม่จำเป็นต้องมีสิทธิ์ Admin เต็ม ให้ Moderator ก็เพียงพอ
2. **อย่าให้สิทธิ์ Admin กับฟรีแลนซ์หรือเอเจนซี่ที่ทำงานระยะสั้น** ควรให้ผ่าน Partner Access ใน Business Manager ที่สามารถถอดสิทธิ์ได้ทันทีเมื่อเลิกงานกัน โดยไม่กระทบ Page หลัก
3. **ตรวจสอบรายชื่อผู้มีสิทธิ์เป็นประจำ** (ทุก 1-3 เดือน) ไปที่ Page Settings > Page Roles เพื่อดูว่ามีใครที่ไม่ควรมีสิทธิ์อยู่แล้วหรือไม่ (เช่น พนักงานที่ลาออกไปแล้ว)
4. **เจ้าของธุรกิจต้องมี Admin อย่างน้อย 2 คนเสมอ** เพื่อป้องกันกรณีบัญชี Admin คนหนึ่งมีปัญหา (ถูกแฮก, ลืมรหัสผ่าน, บัญชีถูกล็อก) จะยังมีอีกคนที่เข้าควบคุม Page ได้

### ข้อผิดพลาดที่พบบ่อย

- ให้สิทธิ์ Admin กับทุกคนในทีมโดยไม่แยกระดับ ทำให้เกิดความเสี่ยงเมื่อมีคนแก้ไขอะไรผิดพลาดโดยไม่ได้รับอนุญาต
- ไม่ถอดสิทธิ์พนักงาน/ฟรีแลนซ์ที่เลิกงานแล้ว ทำให้คนนอกยังเข้าถึง Page ได้อยู่
- มี Admin เพียงคนเดียว และคนนั้นลาออกหรือบัญชีมีปัญหาโดยไม่มีคนสำรอง ทำให้ธุรกิจเข้าไม่ถึง Page ของตัวเองอีกต่อไป

### ตัวอย่างการจัดสิทธิ์ทีมงานตามขนาดธุรกิจ

**ธุรกิจ SME ขนาดเล็ก (1-3 คนดูแล Page):**
- เจ้าของธุรกิจ: Admin
- ผู้จัดการ/หุ้นส่วน: Admin (สำรอง)
- แอดมินตอบแชท: Moderator

**ธุรกิจขนาดกลางที่มีทีมมาร์เก็ตติ้ง:**
- เจ้าของธุรกิจ: Admin (แต่ไม่ค่อยเข้าใช้งานประจำวัน)
- หัวหน้าทีมมาร์เก็ตติ้ง: Admin
- นักยิงแอด: Advertiser
- ทีมคอนเทนต์: Editor
- ทีมแอดมินตอบแชท: Moderator

**เอเจนซี่ที่ดูแลลูกค้าหลายราย:**
- เจ้าของธุรกิจลูกค้า: Admin (เจ้าของ Business Manager)
- เอเจนซี่: ได้รับ Partner Access ระดับ Full Control หรือ Partial Access ตามงานที่ตกลงกัน (รายละเอียดเต็มใน Part 011 Step 105)

การจัดสิทธิ์แบบนี้ช่วยให้เมื่อมีการเปลี่ยนแปลงทีมงาน (คนลาออก, เปลี่ยนเอเจนซี่) ธุรกิจสามารถถอดสิทธิ์คนเดิมและให้สิทธิ์คนใหม่ได้ทันทีโดยไม่กระทบ Page หรือข้อมูลที่สั่งสมมา

## Step 96: Page Verification (Blue Badge) และประโยชน์

### Blue Badge คืออะไร

เครื่องหมายยืนยันตัวตน (Verified Badge) ที่ Meta มอบให้ Page ที่ผ่านการตรวจสอบว่าเป็นธุรกิจ/บุคคล/องค์กรที่มีตัวตนจริงและมีความสำคัญเพียงพอ (Authentic, Unique, Complete, Notable — เกณฑ์ที่ Meta ใช้พิจารณา)

### ประโยชน์ของ Blue Badge

1. **เพิ่มความน่าเชื่อถือทันทีที่ลูกค้าเห็น** — โดยเฉพาะธุรกิจที่มีคู่แข่งจำนวนมากในตลาดเดียวกัน Badge ช่วยแยกความแตกต่างจาก Page ปลอม
2. **ลดความเสี่ยงจาก Page ปลอมแอบอ้าง** — ธุรกิจที่มีคนแอบสร้าง Page ปลอมเลียนแบบบ่อยๆ Badge ช่วยให้ลูกค้าแยกแยะได้ง่ายขึ้น
3. **อาจได้รับ Priority Support บางกรณี** — ไม่ใช่การันตี แต่ Page ที่ผ่านการยืนยันมักถูกจัดลำดับความสำคัญสูงกว่าในบางกระบวนการ

### วิธีขอ Verification (แนวทางทั่วไป — เกณฑ์และหน้าตาฟอร์มอาจเปลี่ยนแปลงตามช่วงเวลา)

ไปที่ **Page Settings > Page Verification** หรือค้นหาคำว่า "Request verified badge" ใน Help Center Meta จะขอเอกสารยืนยันตัวตนทางธุรกิจ เช่น หนังสือรับรองบริษัท, ใบทะเบียนพาณิชย์, หรือเอกสารทางการอื่นๆ ที่แสดงว่าธุรกิจมีตัวตนจริง

### เกณฑ์ที่ Meta พิจารณาโดยสังเขป

- **Authentic** — Page ต้องเป็นตัวแทนของบุคคล/ธุรกิจจริงตามชื่อที่ระบุ
- **Unique** — ไม่มี Page ซ้ำที่ทำหน้าที่เดียวกันจากธุรกิจเดียวกัน (ไม่ควรมี Page สำรองที่ทำหน้าที่ซ้ำกันขอ Verify พร้อมกัน)
- **Complete** — ข้อมูล About, ภาพ, กิจกรรมบน Page ต้องครบถ้วนสมบูรณ์
- **Notable** — Meta พิจารณาว่าธุรกิจ/บุคคลมีความสำคัญเพียงพอ (มักดูจากการถูกค้นหาบ่อย, มีข่าวอ้างอิงจากสื่อ, มีฐานลูกค้าชัดเจน)

### สิ่งที่ต้องรู้ก่อนขอ Verification

Blue Badge **ไม่ใช่สิ่งจำเป็นสำหรับการยิงแอด** — ธุรกิจ SME จำนวนมากยิงแอดได้ผลดีมากโดยไม่มี Badge เลย ดังนั้นไม่ควรมองว่าเป็นสิ่งที่ต้อง "รีบขอ" ก่อนเริ่มทำธุรกิจ แต่เหมาะสำหรับธุรกิจที่เติบโตถึงจุดที่การถูกแอบอ้างเป็นความเสี่ยงจริง หรือธุรกิจที่ต้องการสร้างความน่าเชื่อถือระดับสูงในตลาดที่มีการแข่งขันสูง

### ข้อผิดพลาดที่พบบ่อย

- ยื่นขอ Verification ตั้งแต่ Page ยังใหม่มาก ข้อมูลไม่ครบ ทำให้ถูกปฏิเสธและต้องรออีกนานก่อนยื่นใหม่ได้
- ใช้บริการ "รับจ้างขอ Blue Badge" จากบุคคลที่ไม่น่าเชื่อถือ ซึ่งเสี่ยงต่อการถูกหลอกหรือละเมิดนโยบาย
- เข้าใจผิดว่า Blue Badge ช่วยให้ Ads Performance ดีขึ้นโดยตรง (ไม่มีหลักฐานว่า Badge ส่งผลต่อ Auction โดยตรง — ประโยชน์หลักคือความน่าเชื่อถือในสายตาลูกค้า)

### สิ่งที่ควรทำก่อนยื่นขอ Verification เพื่อเพิ่มโอกาสผ่าน

1. ตรวจสอบว่า About กรอกครบทุกช่องตาม Step 92 แล้ว
2. Page มีกิจกรรมโพสต์อย่างสม่ำเสมอ ไม่ใช่ Page ที่เงียบมานาน
3. เตรียมเอกสารทางธุรกิจให้พร้อม (หนังสือรับรองบริษัท, ใบทะเบียนพาณิชย์, หรือเอกสารยืนยันตัวตนอื่นที่เกี่ยวข้อง)
4. ตรวจสอบว่าไม่มี Page ซ้ำที่ทำหน้าที่เดียวกันในเครือข่ายของธุรกิจเดียวกัน
5. มี Follower/Engagement ในระดับที่แสดงว่าธุรกิจเป็นที่รู้จักจริง ไม่ใช่ Page ที่เพิ่งสร้างแบบไม่มีกิจกรรมใดๆ

## Step 97: Page Templates และ Tabs ที่เหมาะกับธุรกิจ

### Page Template คืออะไร

Meta มี Template สำเร็จรูปที่จัดเรียง Tabs และปุ่มต่างๆ ให้เหมาะกับประเภทธุรกิจ เช่น Template สำหรับร้านค้า, ร้านอาหาร, บริการมืออาชีพ, องค์กรไม่แสวงหาผลกำไร

### วิธีเปลี่ยน Template

ไปที่ **Page Settings > Templates and Tabs** (หรือ Edit Page ในเมนูที่อัปเดต) จะเห็นตัวเลือก Template หลายแบบ พร้อม Preview ว่า Tab ไหนจะถูกจัดลำดับความสำคัญให้เห็นก่อน

### Template ที่ควรเลือกตามประเภทธุรกิจ

| ประเภทธุรกิจ | Template ที่แนะนำ | Tabs สำคัญที่ควรเปิด |
|---|---|---|
| ร้านค้าออนไลน์ | Shopping | Shop, Reviews, Posts |
| ร้านอาหาร/คาเฟ่ | Services / Restaurants & Cafes | Menu, Reviews, Photos, Location |
| บริการมืออาชีพ (ที่ปรึกษา, ทนาย) | Services | About, Reviews, Services |
| คลินิก/ความงาม | Services | Book Now (ถ้ามีระบบจอง), Reviews, Photos |
| Non-profit/องค์กร | Nonprofit | About, Events, Donate |
| Personal Brand/โค้ช | Standard หรือ Services | About, Videos, Posts |
| ธุรกิจ B2B/ที่ปรึกษาองค์กร | Standard | About, Posts, Recommendations |
| สถาบันการศึกษา/คอร์สออนไลน์ | Services | About, Videos, Groups (ถ้ามีชุมชนผู้เรียน) |

### ความสำคัญของ Reviews Tab

สำหรับธุรกิจส่วนใหญ่ **Tab Reviews ควรเปิดไว้เสมอ** ยกเว้นกรณีที่ธุรกิจยังใหม่มากและกลัวรีวิวแรกๆ เป็นลบ (ควรเร่งสร้างรีวิวที่ดีจากลูกค้าจริงก่อน) เพราะ Social Proof จาก Reviews มีผลอย่างมากต่อการตัดสินใจของลูกค้าที่คลิกมาจากโฆษณาแล้วอยากเช็คความน่าเชื่อถือก่อนซื้อ

### ข้อผิดพลาดที่พบบ่อย

- ใช้ Template ผิดประเภท ทำให้ Tab สำคัญ (เช่น Shop) ไม่ถูกแสดงเด่นชัด
- เปิด Tab ที่ไม่มีเนื้อหาอะไรเลย (เช่น เปิด Events Tab แต่ไม่เคยสร้าง Event) ทำให้ดูเหมือน Page ที่ไม่มีการดูแล
- ปิด Reviews Tab เพราะกลัวรีวิวลบ แต่ไม่แก้ปัญหาที่ต้นเหตุ (คุณภาพสินค้า/บริการจริง) ซึ่งเป็นการหลบปัญหาไม่ใช่การแก้ปัญหา

## Step 98: การตั้งค่า Automated Responses และ Instant Reply

การตอบกลับลูกค้าที่รวดเร็วมีผลอย่างมากต่อ Conversion Rate โดยเฉพาะธุรกิจที่ปิดการขายผ่านแชท เพราะลูกค้าออนไลน์มักไม่รอ — ถ้าไม่ตอบใน 2-3 นาที มีโอกาสสูงที่เขาจะไปหาคู่แข่งต่อ

### ฟีเจอร์ที่ควรตั้งค่า

**1. Instant Reply** — ข้อความอัตโนมัติที่ส่งทันทีที่มีคนแชทเข้ามาครั้งแรก ควรมีเนื้อหาที่:
- ทักทายและแจ้งว่าได้รับข้อความแล้ว
- แจ้งเวลาที่แอดมินจะตอบกลับ (เช่น "ทีมงานจะตอบภายใน 15 นาทีในเวลาทำการ")
- ให้ข้อมูลพื้นฐานที่ลูกค้าอาจต้องการทันที (เช่น ลิงก์แคตตาล็อกสินค้า, เบอร์โทรสำรอง)

**2. Away Message** — ข้อความที่ส่งอัตโนมัตินอกเวลาทำการ ควรระบุเวลาทำการชัดเจนและแจ้งว่าจะได้รับการตอบกลับเมื่อไหร่

**3. Frequently Asked Questions (FAQ) Automation** — ตั้งคำถามที่พบบ่อยพร้อมคำตอบสำเร็จรูป เช่น "ราคาสินค้า", "วิธีสั่งซื้อ", "การจัดส่ง" เพื่อลดภาระแอดมินตอบคำถามซ้ำๆ

**4. Guest Chat Plugin (ถ้าใช้ Messenger บนเว็บไซต์)** — ช่วยให้ลูกค้าเริ่มแชทได้แม้ไม่มีบัญชี Facebook

### วิธีตั้งค่า

ไปที่ **Meta Business Suite > Inbox > Automation** (เมนูอาจอยู่ภายใต้ Page Settings > Messaging ในบางเวอร์ชัน) จะเห็นตัวเลือก Instant Reply, Away Message, และ Automation Rules ที่ตั้งเงื่อนไขเพิ่มเติมได้ เช่น ส่งข้อความอัตโนมัติเมื่อมีคน Comment คำเฉพาะใต้โพสต์โฆษณา

### หลักการเขียน Automated Response ที่ดี

- **อย่าให้ดูเป็นบอทมากเกินไป** — ใช้ภาษาที่เป็นธรรมชาติ ไม่ใช่ข้อความทางการแข็งทื่อ
- **ต้องมีทางออกให้คุยกับคนจริงเสมอ** — อย่าปล่อยให้ลูกค้าคุยกับบอทวนไปวนมาโดยไม่มีทางเชื่อมต่อแอดมินจริง
- **อัปเดตข้อมูลใน Automated Response ให้ตรงกับสถานะปัจจุบัน** เช่น ถ้าสินค้าหมด ควรมีข้อความแจ้งทันทีไม่ใช่ให้ลูกค้ารอเก้อ

### ข้อผิดพลาดที่พบบ่อย

- ตั้ง Instant Reply แต่เนื้อหาไม่มีประโยชน์ (เช่น "สวัสดีค่ะ" อย่างเดียวไม่มีข้อมูลอะไรเพิ่ม)
- ไม่ตั้ง Away Message ทำให้ลูกค้าที่แชทนอกเวลาทำการไม่รู้ว่าต้องรอนานแค่ไหน
- ตอบช้ามากแม้จะมี Instant Reply เพราะทีมงานไม่ได้ Monitor Inbox จริงจัง ทำให้ลูกค้ารู้สึกว่าถูกทิ้ง
- ใช้ Automated Response ตอบคำถามที่ซับซ้อนเกินความสามารถของระบบ ทำให้ลูกค้าหงุดหงิดที่ไม่ได้คำตอบตรงคำถาม

## Step 99: Page Quality และการป้องกัน Page ถูกแบน

### Page Quality คืออะไร

หน้า Dashboard ที่ Meta ใช้แสดงสถานะโดยรวมของ Page ว่ามีการละเมิดนโยบายหรือไม่ เข้าถึงได้ที่ **Page Settings > Page Quality** (หรือผ่าน Business Suite > Page Quality) จะแสดง:

1. **Restrictions** — ข้อจำกัดที่ Page กำลังโดนอยู่ (เช่น ไม่สามารถสร้างโฆษณาได้ชั่วคราว)
2. **Violations** — ประวัติการละเมิดนโยบายที่ผ่านมา
3. **Feature Limits** — ฟีเจอร์ที่ถูกจำกัดการใช้งาน

### สัญญาณเตือนที่ต้องระวัง

| สัญญาณ | ความหมาย | ควรทำอย่างไร |
|---|---|---|
| แจ้งเตือน "Your Page's distribution is reduced" | โพสต์/โฆษณาถูกจำกัดการมองเห็นเพราะ Community Standards | ตรวจสอบเนื้อหาที่โพสต์ล่าสุด ลบเนื้อหาที่อาจผิดนโยบาย |
| Ads ถูก Reject บ่อยผิดปกติ | เนื้อหาโฆษณาเข้าข่ายผิดนโยบายซ้ำๆ | ทบทวน Advertising Policies ที่เกี่ยวข้องกับหมวดธุรกิจ |
| Page ถูก Unpublish ชั่วคราว | ละเมิดนโยบายร้ายแรงหรือมีการ Report จำนวนมาก | ยื่น Appeal ทันทีพร้อมเอกสารประกอบ |
| Followers ลดลงผิดปกติ | อาจถูกโจมตีด้วย Fake Report หรือปัญหาด้าน Content | ตรวจสอบ Insights และรายงานผู้ไม่ประสงค์ดีถ้าจำเป็น |

### แนวทางป้องกัน Page ถูกแบน

1. **อย่าซื้อ Like/Follower ปลอม** — Meta มีระบบตรวจจับ Fake Engagement ที่แม่นยำขึ้นทุกปี Page ที่มี Engagement ผิดปกติ (Follower สูงแต่ Engagement ต่ำมาก) มีความเสี่ยงถูกตรวจสอบ
2. **ตรวจสอบเนื้อหาก่อนโพสต์เสมอ โดยเฉพาะหมวดที่มีนโยบายเข้มงวด** (สุขภาพ, การเงิน, ความงาม — รายละเอียดเต็มใน Part 007 และ Part 020)
3. **มี Backup Page เสมอสำหรับธุรกิจที่พึ่งพา Facebook เป็นรายได้หลัก** (รายละเอียดกลยุทธ์ Backup ใน Part 020 Step 196)
4. **ตอบสนองต่อ Warning ทันทีที่ได้รับ** อย่าละเลยแจ้งเตือนแรกๆ เพราะการสะสม Violation จะนำไปสู่การถูกจำกัดที่รุนแรงขึ้นเรื่อยๆ
5. **แยก Personal Account ผู้ดูแล Page ให้ปลอดภัย** เพราะ Page ที่ผูกกับ Personal Account ที่มีประวัติ Spam หรือถูก Report บ่อย มีความเสี่ยงกระทบถึง Page ด้วย

### ข้อผิดพลาดที่พบบ่อย

- ไม่เคยเข้าไปดู Page Quality เลย จนกระทั่ง Page มีปัญหาใหญ่แล้วค่อยมาแก้
- โพสต์เนื้อหา Clickbait หรือ Overclaim ซ้ำๆ จนสะสม Violation จำนวนมาก
- คิดว่าธุรกิจของตัวเอง "ไม่มีทางถูกแบน" เพราะทำถูกกฎหมาย โดยไม่รู้ว่า Community Standards ของ Meta เข้มงวดกว่ากฎหมายทั่วไปในหลายกรณี

### ขั้นตอน Appeal เมื่อ Page ถูก Restrict หรือ Unpublish

1. **อ่านเหตุผลที่ Meta แจ้งอย่างละเอียด** — ไปที่ Page Quality เพื่อดูว่าถูก Flag เรื่องอะไรเจาะจง (เนื้อหาโพสต์ไหน, โฆษณาไหน, หรือ Policy ข้อไหน)
2. **แก้ไข/ลบเนื้อหาที่เป็นต้นเหตุก่อนยื่น Appeal** ถ้ายังมีเนื้อหาที่ผิดนโยบายอยู่ การ Appeal จะไม่สำเร็จ
3. **ยื่น Appeal ผ่านฟอร์มในระบบ** พร้อมคำอธิบายสั้นกระชับ ตรงประเด็น ไม่ต้องเขียนอารมณ์หรือขอความเห็นใจ เพราะ AI Review เป็นผู้พิจารณาขั้นต้น
4. **รอผลตาม Timeline ที่ระบบแจ้ง** ปกติจะได้รับการตอบกลับภายในไม่กี่วัน ถ้าไม่ได้รับคำตอบให้ลองยื่นผ่านช่องทางอื่นเพิ่มเติม เช่น Business Help Center Live Chat (ถ้ามีสิทธิ์เข้าถึง)
5. **ถ้า Appeal ไม่สำเร็จและมั่นใจว่าธุรกิจไม่ได้ผิดจริง** ให้พิจารณาช่องทาง Meta Business Partner หรือ Agency Support ถ้ามีเอเจนซี่ที่เป็น Partner ดูแลอยู่

### สัญญาณที่บอกว่า Page กำลังมีความเสี่ยงสูงขึ้นเรื่อยๆ

- ได้รับ Notification เตือนเรื่องนโยบายมากกว่า 1 ครั้งภายในเดือนเดียว
- Reach ของโพสต์ทั่วไปลดลงฮวบฮาบโดยไม่มีเหตุผลด้าน Algorithm ทั่วไป (เช่น Facebook ลด Organic Reach ทั้งระบบ)
- มี Comment จำนวนมากที่รายงานว่าเป็น Spam หรือหลอกลวง
- โฆษณาถูก Reject ติดต่อกันหลายครั้งในหมวดเนื้อหาเดียวกัน

หากพบสัญญาณเหล่านี้ ควรหยุดพฤติกรรมที่เป็นต้นเหตุทันทีและปรับปรุงคุณภาพเนื้อหา ก่อนที่จะสะสมจนกลายเป็นการถูกจำกัดอย่างถาวร

## Case Study: คลินิกความงาม "Luminous Skin" กับการตั้งค่า Page ที่ผิดพลาด

**สถานการณ์:** Luminous Skin เป็นคลินิกความงามเปิดใหม่ ทำ Page อย่างเร่งรีบเพื่อเริ่มยิงแอดให้เร็วที่สุด โดยพนักงานฝ่ายมาร์เก็ตติ้งสร้าง Page ด้วยบัญชี Personal ของตัวเอง เลือก Category "Beauty, Cosmetic & Personal Care" กรอกข้อมูล About เพียงชื่อกับที่อยู่ ใช้รูปโปรไฟล์เป็นภาพ Stock จากอินเทอร์เน็ต ไม่ตั้งปุ่ม CTA ไม่ตั้ง Instant Reply

**ปัญหาที่พบภายใน 2 เดือน:**

1. พนักงานคนที่สร้าง Page ลาออกกะทันหัน คลินิกไม่มีสิทธิ์ Admin สำรอง ต้องใช้เวลากว่า 3 สัปดาห์ในการติดต่อ Meta Support เพื่อขอสิทธิ์กลับมา (ระหว่างนั้นไม่สามารถยิงแอดหรือแก้ไข Page ได้เลย)
2. ลูกค้าที่คลิกจากแอดเข้ามาดู Page แล้วไม่พบข้อมูลติดต่อ ไม่มีปุ่ม Book Now ทำให้ต้อง Comment ถามใต้โพสต์ ซึ่งกว่าแอดมินจะเห็นและตอบก็ผ่านไปหลายชั่วโมง ลูกค้าจำนวนมากไปคลินิกคู่แข่งแทน
3. รูป Stock Photo ที่ใช้เป็นภาพหน้า Page ทำให้ลูกค้าหลายคน Comment สงสัยว่า "คลินิกนี้มีตัวตนจริงไหม" กระทบความน่าเชื่อถือ

**การแก้ไขที่ทำ (หลังจากตั้ง Business Manager ใหม่ตามหลักการที่ถูกต้อง):**

- ให้เจ้าของคลินิกเป็น Admin หลักผ่าน Business Manager พร้อมมี Admin สำรองอย่างน้อย 1 คน
- กรอก About ครบถ้วน ใส่เวลาทำการ เบอร์โทร ที่อยู่ที่ค้นหาบน Google Maps ได้จริง
- เปลี่ยนภาพโปรไฟล์เป็นโลโก้คลินิกจริง และ Cover Photo เป็นภาพบรรยากาศคลินิกที่ถ่ายเอง
- ตั้งปุ่ม CTA เป็น "Book Now" เชื่อมกับระบบจองออนไลน์
- ตั้ง Instant Reply พร้อมข้อมูลราคาบริการเบื้องต้นและเวลาตอบกลับที่คาดหวัง

**บทเรียน:** การตั้งค่า Page ที่ดูเหมือนเป็นเรื่อง "พื้นฐาน" และถูกมองข้ามบ่อยที่สุด กลับเป็นสาเหตุของปัญหาใหญ่ที่กระทบธุรกิจโดยตรง ทั้งความเสี่ยงด้านสิทธิ์การเข้าถึง และการเสียโอกาสขายจากความน่าเชื่อถือที่ไม่เพียงพอ

**ผลลัพธ์ที่วัดได้หลังแก้ไข:** ภายใน 1 เดือนหลังปรับปรุง Page ตามหลักการที่ถูกต้อง Luminous Skin พบว่าอัตราการตอบกลับลูกค้าเฉลี่ยลดลงจากหลายชั่วโมงเหลือภายในไม่กี่นาทีในเวลาทำการ (จาก Instant Reply ที่ตั้งไว้อย่างมีประโยชน์) และจำนวนคำถามซ้ำๆ ที่แอดมินต้องตอบเองลดลงมาก เพราะข้อมูลราคาพื้นฐานถูกระบุไว้ใน Instant Reply แล้ว ทำให้แอดมินมีเวลาโฟกัสกับลูกค้าที่พร้อมจะจองจริงมากขึ้น

## คำถามที่พบบ่อย (FAQ)

**ถาม: ควรตั้ง Page เป็นภาษาไทยหรือภาษาอังกฤษ?**
ตอบ: ขึ้นอยู่กับกลุ่มลูกค้าเป้าหมายหลัก ถ้าลูกค้าส่วนใหญ่เป็นคนไทย ควรใช้ภาษาไทยเป็นหลักเพราะสร้างความรู้สึกใกล้ชิดและเข้าใจง่ายกว่า ถ้าธุรกิจมีลูกค้าต่างชาติจำนวนมาก อาจพิจารณาทำ Description สองภาษา แต่ชื่อ Page ควรคงที่ภาษาเดียวเพื่อไม่ให้สับสนในการค้นหา

**ถาม: จำเป็นต้องมี Instagram เชื่อมกับ Page ก่อนเริ่มยิงแอดหรือไม่?**
ตอบ: ไม่จำเป็นสำหรับการยิงแอด Facebook แต่ถ้าต้องการให้โฆษณาแสดงบน Instagram Placement ด้วย (ซึ่งแนะนำอย่างยิ่งเพราะเพิ่ม Reach และมักได้ CPM ที่ดีกว่าในหลายอุตสาหกรรม) ควรเชื่อมต่อ Instagram Professional Account เข้ากับ Page ให้เรียบร้อยก่อน

**ถาม: Page ที่มี Like น้อยยิงแอดได้ผลดีไหม?**
ตอบ: ได้ — จำนวน Like ไม่ใช่ปัจจัยหลักที่ Meta ใช้ในการ Optimize โฆษณา (ตามที่อธิบายในสูตร Auction ใน Part 009) แต่จำนวน Like/Social Proof มีผลทางจิตวิทยาต่อลูกค้าที่คลิกเข้ามาดู Page ก่อนตัดสินใจซื้อ ธุรกิจใหม่ที่ยังมี Like น้อยควรเน้นคุณภาพของ Reviews และการตอบลูกค้าที่รวดเร็วเพื่อชดเชยในช่วงแรก

**ถาม: ถ้าโดน Report จาก Page ปลอมที่แอบอ้างชื่อธุรกิจเรา ควรทำอย่างไร?**
ตอบ: รายงาน Page ปลอมนั้นผ่านฟีเจอร์ Report Page ของ Meta ทันที พร้อมเก็บหลักฐานว่า Page ของคุณเป็นตัวจริง (เอกสารธุรกิจ, ประวัติการใช้งานที่ยาวนานกว่า) และพิจารณายื่นขอ Blue Badge (Step 96) เพื่อช่วยลูกค้าแยกแยะ Page จริงจาก Page ปลอมได้ง่ายขึ้นในอนาคต

- [ ] เลือก Category ที่ตรงกับธุรกิจจริงและตระหนักถึงผลกระทบด้านนโยบาย
- [ ] กรอกข้อมูล About ครบทุกช่อง (คำอธิบาย, เว็บไซต์, ที่อยู่, เบอร์โทร, เวลาทำการ)
- [ ] อัปโหลด Profile Picture และ Cover Photo ที่มีคุณภาพและสัดส่วนถูกต้อง
- [ ] ตั้งปุ่ม CTA ให้ตรงกับ Action ที่ต้องการมากที่สุด พร้อมลิงก์ที่มี UTM
- [ ] จัดการ Page Roles ให้มี Admin สำรองอย่างน้อย 2 คน และให้สิทธิ์ตามความจำเป็น

## Workshop / แบบฝึกหัด

### ภารกิจที่ 1: สร้าง Page จริง (หรือปรับปรุง Page ที่มีอยู่)

ถ้ายังไม่มี Page ให้สร้างใหม่ตามขั้นตอน Step 91-92 ถ้ามี Page อยู่แล้ว ให้ตรวจสอบทุกจุดตาม Checklist ข้างต้นและแก้ไขให้ครบ

### ภารกิจที่ 2: ออกแบบภาพ Profile และ Cover Photo

ใช้ Canva หรือเครื่องมือออกแบบที่ถนัด สร้าง Profile Picture และ Cover Photo ตามขนาดที่แนะนำใน Step 93 โดยต้องมี Value Proposition ชัดเจนอยู่ใน Cover Photo

### ภารกิจที่ 3: เขียน Instant Reply และ Away Message

เขียนข้อความ Instant Reply และ Away Message ของธุรกิจตัวเอง/ลูกค้า โดยต้องมี: คำทักทาย, ข้อมูลที่เป็นประโยชน์ทันที, เวลาที่คาดว่าจะตอบกลับ

### ภารกิจที่ 4: ตรวจสอบ Page Roles

เข้า Page Settings > Page Roles (หรือ Business Settings ถ้าผูกกับ Business Manager แล้ว) ตรวจสอบว่ามี Admin กี่คน ใครควรถูกถอดสิทธิ์ ใครควรได้รับสิทธิ์เพิ่ม บันทึกแผนการจัดการสิทธิ์ที่เหมาะสม

### ภารกิจที่ 5: ทำ Page Setup Checklist ฉบับสมบูรณ์

รวบรวมทุกภารกิจข้างต้นเป็นเอกสาร Checklist ฉบับสมบูรณ์ 1 ชุด (ใช้ Google Sheets หรือ Notion) ที่สามารถนำไปใช้ตั้งค่า Page ให้ลูกค้ารายต่อไปได้ทันทีโดยไม่ต้องเริ่มคิดใหม่ทุกครั้ง โดยควรมีคอลัมน์อย่างน้อย: รายการที่ต้องทำ, สถานะ (ทำแล้ว/ยังไม่ทำ), ผู้รับผิดชอบ, วันที่ตรวจสอบล่าสุด เพื่อให้ใช้เป็นเครื่องมือทำงานจริงในทีม ไม่ใช่แค่เอกสารอ้างอิงเฉยๆ

### ภารกิจที่ 6: วิเคราะห์ Page คู่แข่ง 3 ราย

เลือก Page คู่แข่งในธุรกิจเดียวกัน 3 ราย แล้ววิเคราะห์ตามหัวข้อที่เรียนมาทั้งหมดใน Part นี้: Category ที่เลือก, คุณภาพของ Profile/Cover Photo, ปุ่ม CTA ที่ใช้, ความเร็วในการตอบแชท (ลองทักไปถามจริงเพื่อทดสอบ), และ Template/Tabs ที่เปิดใช้ บันทึกสิ่งที่คู่แข่งทำดีกว่าและนำมาปรับใช้กับ Page ของตัวเอง

## สรุปและเชื่อมไปยัง Part ถัดไป

Page ที่ตั้งค่าถูกต้องคือฐานที่มั่นคงสำหรับทุกกิจกรรมการตลาดที่จะเกิดขึ้นต่อจากนี้ ไม่ว่าจะเป็นการยิงแอด การตอบลูกค้า หรือการสร้าง Brand Awareness ในระยะยาว รายละเอียดเล็กๆ ที่ดูเหมือนไม่สำคัญ เช่น การเลือก Category หรือการตั้งปุ่ม CTA กลับมีผลจริงต่อ Conversion Rate และความน่าเชื่อถือของธุรกิจ

ใน **Part 011: Meta Business Suite และ Business Manager เบื้องต้น** เราจะยกระดับการจัดการ Page ของคุณไปอีกขั้น โดยนำ Page ที่สร้างไว้เข้าสู่ Business Manager ซึ่งเป็นระบบบริหารจัดการแบบมืออาชีพที่รวม Page, Pixel, Ad Account ไว้ในที่เดียว พร้อมระบบสิทธิ์ที่ปลอดภัยกว่าการให้สิทธิ์ผ่าน Page Roles แบบเดิม — นี่คือขั้นตอนที่ทำให้ธุรกิจพร้อมสเกลจริงในระดับที่ใหญ่กว่า SME รายเดียว
