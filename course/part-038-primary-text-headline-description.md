Part 036 สอนเรื่อง Hook ที่หยุดคน Part 037 สอนโครงสร้างคอปี้ที่โน้มน้าวใจ (PAS, AIDA, 4U, FAB) — แต่ความรู้ทั้งสองอย่างนี้จะไม่มีประโยชน์เลยถ้าคุณไม่รู้ว่าจะ "วาง" คอปี้ที่เขียนไว้ลงใน 3 ช่องของ Ads Manager อย่างไรให้ได้ผลที่สุด นั่นคือ **Primary Text, Headline, และ Description** — 3 Field ที่หน้าตาดูเรียบง่าย แต่มีกฎเกณฑ์เรื่องความยาว การตัดข้อความ (Truncation) และบทบาทที่ต่างกันโดยสิ้นเชิงในแต่ละ Placement

## Step 371: Character Limit และกฎการตัดข้อความในแต่ละ Placement

### ทำไม Character Limit สำคัญกว่าที่คิด

หลายคนเขียนคอปี้ที่ดีมาก แต่ไม่รู้ว่าข้อความส่วนสำคัญที่สุดถูก Facebook "ตัด" ออกไปเมื่อแสดงบน Placement บางประเภท ผลคือคนเห็นแค่ครึ่งประโยคที่ไม่มีความหมายสมบูรณ์ หรือ Headline ที่ควรจะกระชับกลับถูกตัดกลางคำจนดูไม่เป็นมืออาชีพ Placement ต่างๆ ของ Facebook/Instagram มีพื้นที่แสดงผลไม่เท่ากัน (จอ Feed ต่างจากจอ Story ต่างจากจอ Reels) ทำให้กฎการตัดข้อความต่างกันไปด้วย

### ภาพรวม Field หลักทั้ง 3 และขนาดพื้นที่โดยประมาณ

| Field | ความยาวที่แนะนำให้แสดงครบ | จุดที่มักถูกตัด |
|---|---|---|
| **Primary Text** | ประมาณ 125 ตัวอักษรแรกควรสื่อใจความสำคัญที่สุด | ถูกย่อด้วยปุ่ม "See More" บน Feed หลังจากบรรทัดแรกๆ |
| **Headline** | ประมาณ 27–40 ตัวอักษร ขึ้นกับ Placement | ถูกตัดด้วย "..." เมื่อเกินพื้นที่ที่กำหนดของ Placement นั้น |
| **Description** | ประมาณ 27–30 ตัวอักษร (แสดงเฉพาะบางตำแหน่ง เช่น Feed บนเดสก์ท็อป) | ไม่แสดงเลยในบาง Placement เช่น Stories/Reels |

### ความแตกต่างของการแสดงผลตาม Placement

**Facebook/Instagram Feed:** แสดง Primary Text หลายบรรทัดโดยมีปุ่ม "See More" ตัดหลังจากประมาณ 3-4 บรรทัดแรก (ขึ้นกับอุปกรณ์) Headline และ Description แสดงเป็นตัวหนา/ตัวเล็กใต้ภาพ

**Instagram/Facebook Stories และ Reels:** พื้นที่แนวตั้งเต็มจอ Primary Text มักแสดงแค่ 1-2 บรรทัดแรกก่อนถูกบังด้วยปุ่ม CTA หรือถูกย่อ ไม่มีการแสดง Headline/Description แบบเดียวกับ Feed เพราะพื้นที่ถูกจัดสรรให้ภาพ/วิดีโอเต็มจอเป็นหลัก

**Facebook Right Column / Marketplace:** พื้นที่เล็กมาก Headline อาจถูกตัดเหลือแค่ไม่กี่คำ Primary Text อาจไม่แสดงเลยหรือแสดงแค่บรรทัดแรก

**Audience Network:** แตกต่างกันมากตามแอปที่ไปแสดง บางแอปมีพื้นที่จำกัดมาก ควรออกแบบคอปี้ให้สื่อความหมายได้แม้เห็นแค่ Headline อย่างเดียว

### กฎทองข้อที่สำคัญที่สุด: "ใจความสำคัญที่สุดต้องอยู่ก่อนจุดตัด"

ไม่ว่า Field ไหนก็ตาม หลักการที่ใช้ได้เสมอคือ **ใจความสำคัญที่สุดต้องอยู่ในส่วนที่แสดงผลแน่นอน ไม่ใช่ส่วนที่อาจถูกตัด** สำหรับ Primary Text หมายถึง Hook และประโยคที่กระตุ้นให้กด "See More" ต้องอยู่ใน 125 ตัวอักษรแรก ส่วนรายละเอียด/Objection Handling ที่ยาวกว่าสามารถอยู่ถัดจากนั้นได้ (คนที่สนใจจะกด See More อ่านต่อเอง)

### เจาะลึกเพิ่ม: การทดสอบดูจริงว่าคอปี้ถูกตัดตรงไหน

วิธีที่แม่นยำที่สุดในการรู้ว่าคอปี้จะถูกตัดตรงไหนจริงๆ คือใช้ฟีเจอร์ **Preview** ในหน้า Ad Creation ของ Ads Manager ก่อน Publish ทุกครั้ง Ads Manager มีตัวเลือกดู Preview แยกตาม Placement (Feed, Story, Reels, Marketplace ฯลฯ) ให้เลื่อนดูทุก Placement ที่เลือกไว้ (โดยเฉพาะถ้าใช้ Advantage+ Placements ที่ครอบคลุมหลายที่) เพื่อเช็คว่าคอปี้แสดงผลสมบูรณ์และดูเป็นธรรมชาติในทุกที่หรือไม่ ก่อนเสียงบไปกับครีเอทีฟที่แสดงผลผิดเพี้ยน

### ข้อผิดพลาดที่พบบ่อย

- เขียน Headline ยาวเกินไปโดยไม่เช็ค Preview ทำให้ถูกตัดกลางคำสำคัญ (เช่น "ลดสูงสุด 50% เฉพาะวันนี้เท่านั้น" ถูกตัดเหลือ "ลดสูงสุด 50% เฉพาะวัน...")
- ใส่ข้อมูลสำคัญที่สุดไว้บรรทัดที่ 4-5 ของ Primary Text ทำให้คนที่ไม่กด See More พลาดข้อมูลนั้นไปเลย
- ไม่เช็ค Preview บน Placement ที่แคบที่สุด (Right Column, Marketplace) ทำให้พลาดเห็นว่าคอปี้แสดงผลแย่ในบางที่

## Step 372: โครงสร้าง Primary Text ให้คนกด "See More"

### หลักการพื้นฐาน: 125 ตัวอักษรแรกคือ "Hook ชั้นที่ 2"

Primary Text ทำงานคล้ายกับ Hook ในวิดีโอที่เรียนใน Part 036 — คือส่วนที่ต้อง "หยุดคน" ให้อยากอ่านต่อ แต่แทนที่จะหยุดในเวลา (3 วินาที) มันหยุดใน "พื้นที่" (125 ตัวอักษรแรกก่อนปุ่ม See More) หน้าที่ของ 125 ตัวอักษรแรกไม่ใช่การขายให้จบ แต่เป็นการสร้าง Curiosity/Relevance ให้มากพอที่คนจะกดอ่านต่อ

### โครงสร้างที่แนะนำสำหรับ Primary Text แบบยาว

```
[บรรทัด 1-2: Hook ที่แทงใจ ไม่เกิน 125 ตัวอักษร]
(จบด้วยจุดที่สร้าง Curiosity ให้อยากอ่านต่อ)

--- จุดตัด See More ---

[ส่วนขยาย: Agitate/Interest — รายละเอียดปัญหาหรือเรื่องราว]

[ส่วน Solution/Desire — สินค้าและประโยชน์]

[ส่วน Social Proof — รีวิว/ตัวเลข ถ้ามี]

[CTA ปิดท้าย]
```

### ตัวอย่างจริง — สินค้า: ที่นอนยางพาราลดอาการปวดหลัง

```
[125 ตัวอักษรแรก — ก่อนจุดตัด See More]
ตื่นมาปวดหลังทุกเช้าทั้งที่นอนครบ 8 ชั่วโมง?
ปัญหาอาจไม่ใช่ที่ตัวคุณ แต่เป็นที่นอนที่นอนอยู่ทุกคืน

--- (จุดที่ See More ตัด) ---

หลายคนไม่รู้ว่าที่นอนที่ยวบยาบเกินไปหรือแข็งเกินไป
ทำให้กระดูกสันหลังไม่อยู่ในแนวตรงตลอดคืน สะสมไปนานๆ
กลายเป็นอาการปวดเรื้อรังที่แก้ด้วยยาไม่หายจริง

DreamSoft ที่นอนยางพารา 100% ออกแบบความหนาแน่น 3 ชั้น
รองรับสรีระตามหลักกายภาพบำบัด ลูกค้ากว่า 2,000 คน
รีวิวตรงกันว่าปวดหลังลดลงภายใน 2 สัปดาห์แรก

ทดลองนอน 100 คืน ไม่พอใจคืนเงินเต็มจำนวน
👉 กดสั่งซื้อวันนี้ ผ่อน 0% 10 เดือน
```

สังเกตว่า 125 ตัวอักษรแรก (ก่อนจุดตัด) มีทั้ง Question Hook และ Curiosity Gap อยู่ในตัว ("ปัญหาอาจไม่ใช่ที่ตัวคุณ...") ทำให้คนที่แค่เห็นส่วนที่แสดงผลปกติ (ไม่กด See More) ก็ยังได้รับข้อความที่มีความหมายสมบูรณ์และรู้สึกอยากรู้ต่อ

### เทคนิคการเว้นบรรทัดเพื่อการอ่านบนมือถือ

เพราะคนอ่านโฆษณาบนมือถือเป็นหลัก (มากกว่า 90% ของ Traffic บน Facebook/Instagram) การเว้นบรรทัดมีผลต่อ "ความรู้สึกอยากอ่าน" มาก พารากราฟที่ยาวติดกันเกิน 3-4 บรรทัดจะดูเป็นกำแพงข้อความที่น่าเบื่อ หลักปฏิบัติที่แนะนำ:
- เว้นบรรทัดทุก 1-3 ประโยคที่เป็นความคิดเดียวกัน
- ใช้ Bullet Point (•, ✅, 👉) เมื่อต้องระบุรายการหลายข้อ เพื่อให้สแกนอ่านได้เร็ว
- เว้นบรรทัดคู่ (เว้น 1 บรรทัดเปล่า) ระหว่างการเปลี่ยนหัวข้อความคิด (เช่น จาก Problem ไป Solution)

### เจาะลึกเพิ่ม: กรณีที่ควรเขียน Primary Text สั้น ไม่ต้องยาวเสมอ

Primary Text ไม่จำเป็นต้องยาวเสมอไป สำหรับสินค้าราคาถูก/เข้าใจง่าย หรือ Retargeting Audience ที่รู้จักสินค้าแล้ว การเขียนสั้นกระชับ (ไม่เกิน 1-2 บรรทัด จบในตัวโดยไม่ต้องกด See More) อาจได้ผลดีกว่า เพราะไม่ต้องการให้คนเสียเวลาอ่านมาก แค่ต้องการกระตุ้นให้คลิกทันที ตัวอย่าง:

```
ลดสุดท้าย 50% เฉพาะวันนี้ ของ [สินค้า] ที่คุณดูไว้
👉 กดสั่งก่อนของหมด สต็อกเหลือไม่ถึง 20 ชิ้น
```

หลักการเลือกความยาว: **ยิ่งสินค้าราคาสูง/ซับซ้อน/Cold Audience ยิ่งควรยาวเพื่อให้พื้นที่โน้มน้าว ยิ่งสินค้าราคาถูก/เรียบง่าย/Warm-Hot Audience ยิ่งควรสั้นเพื่อกระตุ้น Action ทันที**

### ข้อผิดพลาดที่พบบ่อย

- เขียน Primary Text ยาวเกินไปโดยไม่มีการเว้นบรรทัดเลย ทำให้แม้แต่คนที่กด See More ก็ยังเจอกำแพงข้อความที่ไม่อยากอ่านต่อ
- ใส่ CTA ไว้ก่อนจุดตัด See More (ในบรรทัดแรกๆ) ทำให้คนกดลิงก์ไปโดยไม่ได้อ่านเนื้อหาที่โน้มน้าวใจเลย ซึ่งจะได้ Traffic ที่ไม่มีคุณภาพ (คลิกเร็วแต่ไม่เข้าใจ Offer)
- เขียน 125 ตัวอักษรแรกเป็นการแนะนำแบรนด์/บริษัทเฉยๆ ("เรา XYZ เป็นผู้นำด้าน...") ทำให้ไม่มี Hook อะไรกระตุ้นให้อ่านต่อ

## Step 373: Headline ที่ดี — Benefit-driven vs Curiosity-driven

### Headline ทำหน้าที่ต่างจาก Primary Text อย่างไร

Headline คือข้อความตัวหนาสั้นๆ ที่แสดงใต้ภาพ/วิดีโอ (ตำแหน่งขึ้นกับ Placement) ทำหน้าที่เป็น **"สรุปสั้นที่สุดของข้อเสนอ"** ต่างจาก Primary Text ที่มีพื้นที่โน้มน้าวยาวกว่า Headline ต้องสื่อสารคุณค่าหลักได้ภายในไม่กี่คำ เพราะพื้นที่จำกัดกว่ามากและมักถูกอ่านแบบ "กวาดตา" ไม่ใช่อ่านละเอียด

### แนวทางที่ 1: Benefit-driven Headline (เน้นประโยชน์ตรงๆ)

บอกประโยชน์หรือข้อเสนอหลักตรงๆ ไม่มีการซ่อนข้อมูล เหมาะกับสินค้าที่ Offer ชัดเจนและน่าดึงดูดในตัวเองอยู่แล้ว (ส่วนลด, ราคา, ผลลัพธ์เฉพาะเจาะจง)

ตัวอย่าง:
```
"ลดสูงสุด 50% แอร์ Inverter ประหยัดไฟ"
"เรียนตัดต่อวิดีโอ จบใน 21 วัน รับงานได้จริง"
"ที่นอนยางพารา ทดลองนอนฟรี 100 คืน"
```

### แนวทางที่ 2: Curiosity-driven Headline (กระตุ้นความอยากรู้)

ไม่เปิดเผยข้อมูลทั้งหมด แต่สร้างช่องว่างความอยากรู้ที่ทำให้คนอยากคลิกเพื่อหาคำตอบ เหมาะกับสินค้าที่ Offer ไม่ได้น่าดึงดูดขนาดที่จะพูดตรงๆ ได้ทันที หรือสินค้าที่ต้องอาศัยการอธิบายเพิ่มก่อนถึงจะเข้าใจคุณค่า

ตัวอย่าง:
```
"เหตุผลที่หมอฟันไม่อยากให้คุณรู้"
"สิ่งที่คนขายของออนไลน์เก่งๆ ทำต่างจากคนอื่น"
"ทำไมที่นอนที่แพงที่สุด ไม่ใช่ที่นอนที่ดีที่สุด"
```

### ตารางเปรียบเทียบเมื่อไหร่ควรใช้แบบไหน

| ปัจจัย | Benefit-driven | Curiosity-driven |
|---|---|---|
| Offer แข็งแรงมาก (ส่วนลดสูง/ราคาดี) | ใช้ได้ผลดี | อาจเสียโอกาสถ้าไม่บอก Offer ตรงๆ |
| Audience เป็น Cold ไม่รู้จักสินค้าเลย | ใช้ได้ แต่ต้อง Relevance สูง | ใช้ได้ดีมาก เพราะสร้างความอยากรู้ก่อนขาย |
| Audience เป็น Retargeting | ใช้ได้ดีมาก เพราะรู้จัก Offer แล้ว อยากเห็นตัวเลขชัดๆ | อาจดูเยิ่นเย้อเพราะเขารู้จักสินค้าแล้ว |
| สินค้าที่มูลค่าซับซ้อน ต้องอธิบายก่อนเข้าใจ | ยากที่จะสรุปเป็นประโยคเดียว | เหมาะกว่า เพราะดึงให้อ่าน Primary Text ก่อน |
| ความเสี่ยง Policy | ต่ำ (ตรงไปตรงมา) | ต้องระวังไม่ให้เป็น Clickbait |

### เจาะลึกเพิ่ม: Headline กับ Ultra-specific จาก 4U

Headline ที่ดีที่สุดมักมีคุณสมบัติ Ultra-specific จากหลัก 4U ที่เรียนใน Part 037 — การใส่ตัวเลขที่เจาะจง (เปอร์เซ็นต์, จำนวนวัน, จำนวนคน) ทำให้ Headline น่าเชื่อถือและดึงดูดกว่า Headline ที่เขียนแบบกว้างๆ เปรียบเทียบ:

```
กว้างเกินไป: "สินค้าคุณภาพดี ราคาคุ้มค่า"
Ultra-specific: "ลด 50% เหลือ 990 บาท จาก 1,990 บาท วันนี้เท่านั้น"
```

### ข้อผิดพลาดที่พบบ่อย

- เขียน Headline ที่ซ้ำกับ Primary Text เป๊ะๆ ทำให้เสียโอกาสในการสื่อสารมุมมองที่ต่างออกไปหรือเสริมข้อมูลใหม่
- ใช้ Curiosity-driven Headline ที่คลุมเครือเกินไปจนคนไม่รู้เลยว่าเกี่ยวกับอะไร (ต่างจาก Curiosity Gap ที่ดีซึ่งต้องมี "ปม" ที่ชัดเจนพอจะรู้ทิศทาง)
- ไม่ทดสอบทั้ง 2 แบบเลย ใช้แบบเดียวตลอดโดยไม่รู้ว่าแบบไหนเหมาะกับสินค้า/Audience ของตัวเองมากกว่า

## Step 374: บทบาทของ Description Field

### Description คือ Field ที่ถูกมองข้ามบ่อยที่สุด

Description เป็น Field เล็กๆ ที่แสดงผลเฉพาะบางตำแหน่ง (ส่วนใหญ่คือ Feed บนเดสก์ท็อป และบางส่วนของ Feed มือถือ) ทำให้หลายคนมองว่า "ไม่สำคัญเท่า Headline" และมักเว้นว่างไว้หรือใส่ข้อมูลซ้ำแบบไม่ตั้งใจ แต่ Description มีบทบาทเฉพาะที่มีประโยชน์ถ้าใช้ถูกวิธี

### บทบาทที่ Description ทำได้ดี

**1. เสริมข้อมูลเชิงตรรกะ/เหตุผล** — ในขณะที่ Headline โฟกัสที่ประโยชน์/ความอยากรู้ Description สามารถเติมรายละเอียดเชิงเหตุผล (Logical Reasoning) ที่สนับสนุน Headline เช่น ถ้า Headline คือ "ลด 50% วันนี้เท่านั้น" Description สามารถเป็น "เฉพาะสมาชิกใหม่ 100 คนแรก"

**2. เพิ่ม Trust Signal สั้นๆ** — เช่น "รับประกันคืนเงิน 30 วัน" หรือ "จัดส่งฟรีทั่วประเทศ"

**3. ระบุเงื่อนไข/ข้อมูลที่ป้องกันความเข้าใจผิด** — เช่น "ราคานี้สำหรับแพ็กเกจพื้นฐานเท่านั้น" ช่วยกรอง Traffic ที่ไม่ตรงกลุ่มออกไปก่อนคลิก ลดปัญหา Lead ไม่มีคุณภาพ

### ตัวอย่างการจัดวาง Headline + Description ที่ทำงานร่วมกัน

```
Headline: "คอร์สยิงแอด Facebook จบใน 21 วัน"
Description: "เฉพาะ 30 คนแรก ราคาพิเศษ 1,490 บาท"
```

```
Headline: "ที่นอนยางพารา ทดลองนอนฟรี 100 คืน"
Description: "ไม่พอใจคืนเงินเต็มจำนวน ไม่มีเงื่อนไข"
```

### เจาะลึกเพิ่ม: Description ในมุมของ Ad Format ที่ต่างกัน

สำหรับ Carousel Ads (จะเรียนเจาะลึกใน Part 042) แต่ละการ์ดสามารถมี Headline/Description ของตัวเองแยกกันได้ ทำให้ Description กลายเป็นเครื่องมือสำคัญในการ "เล่าเรื่องต่อเนื่อง" ข้ามการ์ด เช่น การ์ดที่ 1 Description เป็น "ขั้นที่ 1: ค้นหาปัญหา" การ์ดที่ 2 เป็น "ขั้นที่ 2: วิเคราะห์" ทำให้คนอยากเลื่อนดูการ์ดถัดไปเพื่อติดตามเรื่องราวให้ครบ

### ข้อผิดพลาดที่พบบ่อย

- เว้น Description ว่างไว้เสมอเพราะคิดว่าไม่สำคัญ ทั้งที่ในบาง Placement (โดยเฉพาะเดสก์ท็อป) Description ที่มีเนื้อหาดีช่วยเพิ่ม Conversion ได้จริง
- ใส่ข้อมูลซ้ำกับ Headline เป๊ะๆ โดยไม่ได้เพิ่มมูลค่าอะไรใหม่
- ใส่ข้อความยาวเกินจนถูกตัด (Description มีพื้นที่จำกัดกว่า Headline อีก) ทำให้อ่านไม่จบความ

## Step 375: การเลือก CTA Button ให้เข้ากับคอปี้

### CTA Button คืออะไร ทำไมเลือกผิดได้ง่าย

CTA (Call-to-Action) Button คือปุ่มสำเร็จรูปที่ Facebook ให้เลือกจาก Dropdown (เช่น "Shop Now", "Learn More", "Sign Up", "Send Message", "Download", "Get Quote") ซึ่งดูเหมือนเป็นรายละเอียดเล็กๆ แต่ปุ่มที่ไม่ตรงกับความคาดหวังของคนอ่านคอปี้จะสร้างความสับสนหรือลดความน่าเชื่อถือทันที เพราะปุ่มคือ "คำสัญญาสุดท้าย" ก่อนคลิก

### ตารางจับคู่ CTA Button กับสถานการณ์

| CTA Button | เหมาะกับสถานการณ์ |
|---|---|
| **Shop Now (สั่งซื้อเลย)** | Conversion Campaign ที่มี Landing Page ขายสินค้าตรง พร้อมให้ซื้อทันที |
| **Learn More (ดูเพิ่มเติม)** | Traffic/Awareness ที่ยังต้องการให้ข้อมูลก่อน ยังไม่เร่งปิดขาย |
| **Sign Up (ลงทะเบียน)** | Lead Generation, สมัครสมาชิก, ลงทะเบียนคอร์ส/Event |
| **Send Message (ส่งข้อความ)** | Click-to-Messenger/WhatsApp Campaign ที่ต้องการให้ทักแชท |
| **Get Quote (ขอใบเสนอราคา)** | ธุรกิจ B2B, บริการที่ราคาต้องคุยเฉพาะเจาะจง (ประกัน, ก่อสร้าง) |
| **Download (ดาวน์โหลด)** | App Install, การดาวน์โหลด E-book/Lead Magnet |
| **Book Now (จองเลย)** | ธุรกิจที่ต้องนัดเวลา (คลินิก, ร้านเสริมสวย, ร้านอาหาร) |
| **Subscribe (ติดตาม)** | คอนเทนต์/สื่อที่ต้องการยอดติดตามระยะยาว |

### หลักการจับคู่ CTA กับคอปี้ให้สอดคล้องกัน

CTA Button ต้อง "ตรงกับสิ่งที่คอปี้สัญญาไว้" เสมอ ถ้าคอปี้เขียนแบบเร่งขาย ("กดสั่งซื้อวันนี้") แต่ CTA Button เป็น "Learn More" จะสร้างความรู้สึกไม่สอดคล้องกัน (Dissonance) เล็กน้อยที่ลดอัตราการคลิก ในทางกลับกัน ถ้าคอปี้เพิ่งเริ่มให้ข้อมูล (Awareness) แต่ CTA เป็น "Shop Now" อาจทำให้คนที่ยังไม่พร้อมซื้อรู้สึกถูกเร่งเกินไปและไม่คลิกเลย

### เจาะลึกเพิ่ม: การทดสอบ CTA Button เป็นตัวแปรที่คนมองข้าม

หลายคนทดสอบ A/B แค่ Primary Text หรือ Headline แต่ไม่เคยทดสอบ CTA Button ทั้งที่บางครั้งความต่างระหว่าง "Learn More" กับ "Shop Now" สำหรับ Landing Page เดียวกันสามารถให้ผล CTR ต่างกันได้หลาย % เพราะมันเปลี่ยนความคาดหวังของคนก่อนคลิกโดยตรง แนะนำให้รวม CTA Button เป็นหนึ่งในตัวแปรที่ทดสอบอย่างเป็นระบบตามที่จะเรียนใน Step 379

### ข้อผิดพลาดที่พบบ่อย

- เลือก CTA Button ตามความเคยชิน (ใช้ "Learn More" ทุกแคมเปญไม่ว่า Objective จะเป็นอะไร) โดยไม่พิจารณาว่าเหมาะกับสถานการณ์จริงหรือไม่
- ใช้ CTA ที่เร่งเกินไป (Shop Now) กับ Landing Page ที่จริงๆ เป็นแค่หน้าให้ข้อมูล ทำให้คนรู้สึกผิดหวังหลังคลิก (Bounce สูง)
- ไม่รู้ว่า CTA Button บางตัวถูกจำกัดตาม Objective ที่เลือกไว้ (บาง Objective มี CTA ให้เลือกจำกัดกว่า Objective อื่น) ทำให้งงว่าทำไมหา CTA ที่ต้องการไม่เจอ

## Step 376: เขียนคอปี้ต่างกันสำหรับ Cold / Warm / Hot Audience

### ทำไม Field เดียวกัน ต้องเขียนต่างกันตาม Audience

หลักการนี้ต่อเนื่องมาจาก Step 358 ใน Part 036 ที่พูดถึง Hook ตาม Funnel Stage — แต่ในระดับ Primary Text/Headline/Description ต้องลงรายละเอียดมากกว่านั้น เพราะทั้ง 3 Field ต้องทำงานสอดคล้องกันตามระดับความรู้จักสินค้าของคนอ่าน

### คอปี้สำหรับ Cold Audience — เน้นให้ความรู้ + สร้าง Self-Recognition

```
Primary Text:
เคยเป็นไหม? เปิดตู้เสื้อผ้าเต็มไปด้วยเสื้อผ้า
แต่หาชุดที่ใส่ไปทำงานแล้วดูมั่นใจไม่ได้เลยสักตัว

ปัญหานี้ไม่ใช่เพราะคุณมีเสื้อผ้าน้อยเกินไป
แต่เพราะไม่มีใครช่วยจัดชุดที่เข้ากับโทนสีผิว/รูปร่างจริงๆ

StyleMatch บริการจัดสไตล์ออนไลน์ที่วิเคราะห์โทนสี
และรูปร่างของคุณ แล้วแนะนำชุดที่เหมาะที่สุดใน 24 ชม.

Headline: "จัดสไตล์ออนไลน์ เข้ากับตัวคุณจริง"
Description: "วิเคราะห์ฟรี ไม่มีค่าใช้จ่ายในการปรึกษาครั้งแรก"
CTA: Learn More
```

### คอปี้สำหรับ Warm Audience — อ้างอิงสิ่งที่เขาเคยสนใจ + แก้ Objection

```
Primary Text:
ยังลังเลเรื่อง StyleMatch อยู่ไหม?

เข้าใจว่าการให้คนอื่นช่วยเลือกเสื้อผ้าอาจฟังดูแปลกใหม่
แต่ลูกค้ากว่า 800 คนบอกว่าหลังใช้บริการ
พวกเขาซื้อเสื้อผ้าผิดแบบน้อยลง ประหยัดเงินได้มากกว่าค่าบริการหลายเท่า

Headline: "800+ คนพอใจ ลองดูรีวิวจริง"
Description: "รับประกันความพอใจ หรือคืนเงิน 100%"
CTA: Learn More หรือ Sign Up
```

### คอปี้สำหรับ Hot Audience / Retargeting — กระตุ้นตัดสินใจทันที

```
Primary Text:
ตะกร้าของคุณยังมี Style Guide ที่เลือกไว้ค้างอยู่
วันนี้เท่านั้น รับส่วนลด 15% เมื่อสมัครภายในคืนนี้

Headline: "ส่วนลด 15% หมดเที่ยงคืนนี้"
Description: "เฉพาะคนที่เคยดูบริการนี้แล้วเท่านั้น"
CTA: Shop Now
```

### ตารางสรุปแนวทางการเขียนตาม Audience Temperature

| องค์ประกอบ | Cold | Warm | Hot |
|---|---|---|---|
| Primary Text เน้น | ปัญหา/การให้ความรู้ | Social Proof/แก้ Objection | Urgency/ข้อเสนอเฉพาะ |
| Headline เน้น | Curiosity/Benefit ทั่วไป | ตัวเลข/รีวิว | ส่วนลด/กำหนดเวลา |
| ความยาวคอปี้ | ยาวกว่า (ต้องอธิบาย) | ปานกลาง | สั้น กระชับ |
| CTA ที่เหมาะ | Learn More | Learn More/Sign Up | Shop Now/Book Now |

### เจาะลึกเพิ่ม: การจัดการ Custom Audience ให้สอดคล้องกับคอปี้ที่ต่างกัน

การเขียนคอปี้ตาม Audience Temperature ให้ได้ผลจริง ต้องมีการแบ่ง Custom Audience อย่างเป็นระบบก่อน (จะเรียนละเอียดใน Part 047) เช่น สร้าง Custom Audience จากคนที่เคย Engage กับเพจ (Warm) แยกจากคนที่เคยเข้าเว็บแต่ไม่ซื้อ (Warm ระดับสูงกว่า) แยกจากคนที่เคยซื้อแล้ว (Hot) — ถ้าไม่มีการแบ่งกลุ่มที่ชัดเจน การเขียนคอปี้ 3 ระดับก็ไม่มีที่ให้ใช้งานจริง

### ข้อผิดพลาดที่พบบ่อย

- ใช้คอปี้ Cold Audience (ที่อธิบายพื้นฐานยาวๆ) ไปยิงกับ Retargeting Audience ทำให้รู้สึกเหมือนแบรนด์ "ไม่รู้จัก" พวกเขาเลย
- ใช้คอปี้ Hot Audience (Urgency แรงๆ) ไปยิงกับ Cold Audience ที่ยังไม่รู้จักแบรนด์ ทำให้ดูเป็นการเร่งขายเกินไปจนน่าสงสัย
- ไม่มีระบบ Custom Audience แยกตาม Temperature ทำให้ต้องใช้คอปี้แบบเดียวกับทุกกลุ่มโดยไม่มีทางเลือกอื่น

## Step 377: Localization — ภาษาไทยที่ Convert จริง vs ภาษาที่ดูเป็นสแปม

### ปัญหาของการแปลตรงจากภาษาอังกฤษ

หนังสือ/คอร์ส Copywriting ส่วนใหญ่ในตลาดเป็นเนื้อหาจากต่างประเทศ ทำให้นักคอปี้ไทยจำนวนมากแปลสูตร/ประโยคจากภาษาอังกฤษตรงตัวจนฟังดูแปลกในภาษาไทย เช่น "ปลดล็อกศักยภาพที่แท้จริงของคุณ" หรือ "เปลี่ยนเกมชีวิตคุณไปตลอดกาล" ซึ่งฟังดูเป็นธรรมชาติในภาษาอังกฤษ แต่ในภาษาไทยกลับฟังดูเวอร์และไม่จริงใจสำหรับกลุ่มเป้าหมายจำนวนมาก (ยกเว้นบางกลุ่ม เช่น สาย Self-Help/Motivation ที่คุ้นกับสำนวนแบบนี้อยู่แล้ว)

### สัญญาณของภาษาที่ "ดูเป็นสแปม" ในสายตาคนไทย

1. **การใช้ตัวพิมพ์ใหญ่/เครื่องหมายตกใจมากเกินไป** — "ด่วนที่สุด!!! โอกาสสุดท้าย!!!" ยิ่งใส่มากยิ่งดูน่าสงสัย
2. **คำที่ Overclaim แบบสัมบูรณ์** — "หายขาด 100%", "รวยแน่นอน", "การันตีทุกคน" มักเป็นสัญญาณเตือนที่คนไทยยุคนี้ระแวงมาก เพราะเคยเจอโฆษณาหลอกลวงจำนวนมาก
3. **การอ้างชื่อคนดัง/แพทย์แบบไม่มีที่มา** — "หมอแนะนำ" โดยไม่ระบุว่าหมอคนไหน คลินิกไหน
4. **Emoji ที่ใส่พร่ำเพรื่อจนดูรก** — ใส่ Emoji ทุกคำจนข้อความอ่านยาก (จะเรียนละเอียดใน Step 378)
5. **การซ้ำคำเดิมหลายรอบเพื่อเน้น** — "ลดคับ ลดจริง ลดแรง ลดสุด" ซึ่งเป็นสูตรที่ถูกใช้จนคนไทยรู้สึกชินและระแวงทันทีที่เห็น

### ภาษาไทยที่ Convert จริง — ลักษณะร่วมที่พบในคอปี้ที่ได้ผล

**1. ใช้ภาษาพูดที่เป็นธรรมชาติ ไม่ใช่ภาษาเขียนทางการ** — เช่น "เคยเป็นไหม" ดีกว่า "ท่านเคยประสบปัญหาดังต่อไปนี้หรือไม่"

**2. ระบุตัวเลข/รายละเอียดที่ตรวจสอบได้** — "ลูกค้า 2,347 คน" น่าเชื่อกว่า "ลูกค้ามากมาย"

**3. ยอมรับข้อจำกัด/เงื่อนไขอย่างตรงไปตรงมา** — "ผลลัพธ์แต่ละคนอาจแตกต่างกัน" หรือ "ใช้เวลาเห็นผลต่างกันไปตามแต่ละคน" สร้างความน่าเชื่อถือมากกว่าการอ้างว่าได้ผล 100% ทุกคน

**4. ใช้คำลงท้ายที่เป็นธรรมชาติตามกลุ่มเป้าหมาย** — "ค่ะ/ครับ" สำหรับกลุ่มผู้ใหญ่/เป็นทางการ, ไม่มีคำลงท้ายเลยสำหรับกลุ่มวัยรุ่นที่นิยมภาษาห้วนกระชับ

### ตัวอย่างเปรียบเทียบ — สินค้า: ครีมลดเลือนริ้วรอย

**ดูเป็นสแปม:**
```
"🔥🔥 สุดยอดครีมมหัศจรรย์!! ลบริ้วรอยหายภายใน 3 วัน
รับประกัน 100% ทุกคนใช้แล้วเด็กลง 10 ปี!! สั่งด่วนก่อนหมด!! 🔥🔥"
```

**Convert จริง:**
```
"ริ้วรอยรอบตาที่เริ่มเห็นชัดตอนยิ้ม เป็นสัญญาณที่หลายคน
เริ่มสังเกตตอนอายุ 30 ต้นๆ

ครีม RenewLine ใช้สาร Retinol เข้มข้นที่ผ่านการทดสอบทางคลินิก
จากผู้ใช้จริง 1,240 คน กว่า 70% สังเกตเห็นริ้วรอยตื้นขึ้น
ภายใน 4 สัปดาห์การใช้อย่างต่อเนื่อง (ผลลัพธ์อาจแตกต่างกันไปในแต่ละบุคคล)

ทดลองใช้ไซส์เล็ก 199 บาท ก่อนตัดสินใจซื้อไซส์เต็ม"
```

### เจาะลึกเพิ่ม: ความแตกต่างของภาษาที่ Convert ระหว่างภูมิภาค/กลุ่มอายุ

ภาษาไทยที่ Convert สำหรับกลุ่มเป้าหมายในกรุงเทพฯ/หัวเมืองใหญ่ อาจต่างจากกลุ่มเป้าหมายในพื้นที่ต่างจังหวัด — กลุ่มเมืองมักตอบสนองดีกับภาษาที่กระชับ ตรงประเด็น มีข้อมูล/ตัวเลขสนับสนุน ในขณะที่บางกลุ่มเป้าหมายในต่างจังหวัดอาจตอบสนองดีกับภาษาที่อบอุ่น เป็นกันเอง มีความรู้สึกเหมือนคุยกับคนรู้จักมากกว่าภาษาที่เป็นทางการหรือเน้นข้อมูล ควรทดสอบทั้งสองแนวทางเมื่อขยายตลาดไปยังกลุ่มเป้าหมายใหม่ ไม่ควรใช้สูตรภาษาเดียวกับทุกพื้นที่ทุกกลุ่มอายุโดยไม่ทดสอบ

### ข้อผิดพลาดที่พบบ่อย

- แปลสำนวนภาษาอังกฤษตรงตัวจนฟังดูไม่เป็นธรรมชาติในภาษาไทย
- ใช้คำ Overclaim แบบสัมบูรณ์ ("100% ทุกคน", "หายขาด") ที่ทั้งดูไม่น่าเชื่อถือและเสี่ยงผิด Policy
- คิดว่าภาษาที่ใช้ได้ผลกับกลุ่มเป้าหมายกลุ่มหนึ่งจะใช้ได้ผลกับทุกกลุ่มเป้าหมายเหมือนกัน โดยไม่ทดสอบ Tone ที่ต่างกัน

## Step 378: หลักการใช้ Emoji ในคอปี้โฆษณา

### Emoji มีประโยชน์จริง แต่ต้องใช้อย่างมีเหตุผล

Emoji ไม่ใช่แค่ "ของประดับ" ที่ใส่ให้ดูน่ารัก แต่มีบทบาทที่ใช้งานได้จริง 3 อย่าง:

**1. เป็นตัวแบ่งจังหวะการอ่าน (Visual Break)** — ช่วยให้ตาสแกนหาจุดสำคัญได้เร็วขึ้นในคอปี้ยาว
**2. แทนที่ Bullet Point ในการเรียงรายการ** — ทำให้ดูเป็นระเบียบและน่าอ่านกว่าข้อความล้วน
**3. สื่ออารมณ์/บริบทที่ข้อความล้วนสื่อได้ไม่ชัด** — เช่น 😅 สื่อความรู้สึกกวนๆ/เข้าใจในสถานการณ์

### หลักการใช้ Emoji อย่างมีชั้นเชิง

**1. ใช้ Emoji ที่มีความหมายตรงกับเนื้อหา ไม่ใช่ใส่แบบสุ่ม** — 🎂 สำหรับเค้ก/วันเกิด, 💪 สำหรับฟิตเนส/ความแข็งแรง, 🏠 สำหรับอสังหาริมทรัพย์ ไม่ใช่ใส่ 🔥✨💯 แบบเดิมซ้ำๆ กับทุกสินค้าไม่ว่าจะขายอะไร

**2. จำกัดจำนวน Emoji ต่อประโยค** — ไม่เกิน 1 Emoji ต่อประโยค ยกเว้นตอนใช้แทน Bullet Point ในรายการ

**3. ใช้ Emoji เป็นตัวเปิด Bullet Point ได้อย่างมีประสิทธิภาพ:**
```
✅ ทดลองใช้ฟรี 7 วัน
✅ ยกเลิกได้ทุกเมื่อ ไม่มีข้อผูกมัด
✅ ทีมงานตอบแชทภายใน 5 นาที
```

**4. หลีกเลี่ยง Emoji ในกลุ่มธุรกิจที่ต้องการความน่าเชื่อถือสูง** — บริการทางการแพทย์ กฎหมาย การเงิน B2B ควรใช้ Emoji อย่างประหยัดมากหรือไม่ใช้เลย เพราะอาจลดความน่าเชื่อถือในสายตากลุ่มเป้าหมายที่ต้องการความเป็นทางการ

### ตัวอย่างการใช้ Emoji ที่พอเหมาะ vs มากเกินไป

**มากเกินไป (ดูรก/สแปม):**
```
🔥🔥ลดสุดๆ!!!💥💥 ครีมหน้าใส✨✨ ใช้แล้วปัง🙌🙌
สั่งเลย!!!📱📱 ก่อนหมด⏰⏰
```

**พอเหมาะ (อ่านง่าย มีจุดโฟกัส):**
```
ครีมหน้าใสสูตรใหม่ ลด 30% วันนี้เท่านั้น

✅ อ่อนโยน ไม่ระคายเคือง
✅ ใช้ได้ทุกสภาพผิว
✅ เห็นผลใน 2 สัปดาห์

👉 กดสั่งซื้อก่อนโปรหมดคืนนี้
```

### เจาะลึกเพิ่ม: Emoji กับการแสดงผลบนอุปกรณ์ต่างกัน

Emoji บางตัวแสดงผลต่างกันเล็กน้อยระหว่างระบบ iOS และ Android (สีหรือรูปทรงต่างกันบ้าง) แต่โดยรวมยังสื่อความหมายเดียวกัน ไม่ใช่ปัญหาใหญ่ ข้อควรระวังที่สำคัญกว่าคือ Emoji บางตัวมีความหมายต่างกันในบริบทวัฒนธรรมต่างกัน (เช่น Emoji บางตัวที่ดูปกติในวัฒนธรรมหนึ่งอาจดูไม่เหมาะสมในอีกวัฒนธรรม) สำหรับตลาดไทยควรเลือก Emoji ที่ใช้กันทั่วไปในโซเชียลมีเดียไทยอยู่แล้ว (👍✅💰🎉🏠💪🎂 ฯลฯ) และเลี่ยง Emoji ที่ไม่คุ้นเคยหรือความหมายไม่ชัดเจนในบริบทไทย

### ข้อผิดพลาดที่พบบ่อย

- ใส่ Emoji เดิมซ้ำๆ ในทุกสินค้าไม่ว่าจะขายอะไร (เช่นใส่ 🔥 ทุกโพสต์) จนดูเหมือนสูตรสำเร็จที่ไม่ได้คิด ไม่ใช่ Emoji ที่เลือกมาเพื่อสื่อความหมายจริง
- ใส่ Emoji ในกลุ่มธุรกิจที่ต้องการความน่าเชื่อถือสูงจนดูไม่เป็นทางการเกินไปสำหรับกลุ่มเป้าหมาย
- ใช้ Emoji แทนคำอธิบายทั้งหมด (เช่น ใช้ Emoji แทนคำที่ควรอธิบายเป็นข้อความ) ทำให้สื่อความหมายไม่ครบถ้วน

## Step 379: A/B Testing ตัวแปรคอปี้อย่างเป็นระบบ

### หลักการพื้นฐาน: เปลี่ยนทีละตัวแปร

เช่นเดียวกับการทดสอบ Hook ที่เรียนใน Part 036 Step 356 การทดสอบคอปี้ต้องแยกตัวแปรให้ชัดเจน ไม่เปลี่ยนหลายอย่างพร้อมกัน ตัวแปรหลักที่ควรทดสอบแยกกันในคอปี้ ได้แก่:

1. **Primary Text** (ทั้งชิ้นหรือแค่ Hook 125 ตัวอักษรแรก)
2. **Headline** (Benefit-driven vs Curiosity-driven)
3. **Description**
4. **CTA Button**
5. **ความยาวโดยรวม** (สั้น vs ยาว)
6. **Tone of Voice** (เป็นทางการ vs เป็นกันเอง)

### วิธีตั้งการทดสอบที่แนะนำ: ทีละตัวแปร

```
Test Round 1: ทดสอบ Primary Text (3 versions)
- คุม Headline, Description, CTA, Audience, Budget ให้เหมือนกันหมด
- เปลี่ยนแค่ Primary Text เป็น 3 เวอร์ชัน (ใช้ Framework ต่างกัน เช่น PAS vs AIDA vs 4U)
- รันจนได้ Impression/Result เพียงพอ (แนะนำอย่างน้อย 1,000-2,000 Impression ต่อเวอร์ชัน)
- บันทึกผล CTR, CPC, Cost per Result ของแต่ละเวอร์ชัน

Test Round 2: นำ Primary Text ที่ชนะจาก Round 1 มาทดสอบ Headline
- คุม Primary Text (ตัวที่ชนะ), Description, CTA ให้เหมือนกัน
- เปลี่ยนแค่ Headline เป็น Benefit-driven vs Curiosity-driven

Test Round 3: นำ Primary Text + Headline ที่ชนะ มาทดสอบ CTA Button
- เปลี่ยนแค่ CTA Button (เช่น Learn More vs Shop Now)
```

### การใช้ Dynamic Creative เพื่อทดสอบหลายตัวแปรพร้อมกันอย่างมีระบบ

Meta มีฟีเจอร์ **Dynamic Creative** ที่อนุญาตให้อัปโหลดหลาย Primary Text, หลาย Headline, หลายภาพพร้อมกัน แล้วให้ระบบ Machine Learning ทดลองผสมคู่กันเองและเรียนรู้ว่าคู่ไหนได้ผลดีที่สุดกับ Audience แต่ละคน วิธีนี้เร็วกว่าการทดสอบทีละตัวแปรแบบ Manual แต่มีข้อเสียคือ **ไม่สามารถแยกวิเคราะห์ได้ชัดเจนเท่าการทดสอบแบบควบคุมตัวแปร** (Meta ไม่เปิดเผยรายละเอียดว่าคู่ผสมไหนถูกแสดงให้ใครกี่ครั้ง) เหมาะกับการใช้เมื่อต้องการ Performance เร็วโดยไม่ต้องวิเคราะห์ลึก มากกว่าการใช้เพื่อเรียนรู้ Insight เชิงลึกเกี่ยวกับคอปี้ (การทดสอบเชิงลึกที่ต้องการ Insight ควรใช้วิธี Manual A/B Test แบบควบคุมตัวแปรที่อธิบายข้างต้น)

### Metric ที่ควรดูในการตัดสินผลคอปี้

| Metric | บอกอะไร |
|---|---|
| CTR (Click-Through Rate) | คอปี้ดึงดูดให้คลิกได้ดีแค่ไหน |
| CPC (Cost per Click) | ต้นทุนต่อคลิก สัมพันธ์กับ CTR และ Relevance |
| Cost per Result | ต้นทุนต่อผลลัพธ์จริงตาม Objective (Lead, Purchase) — Metric ที่สำคัญที่สุดในการตัดสินคอปี้ท้ายที่สุด |
| CTR สูงแต่ Conversion ต่ำ | สัญญาณว่าคอปี้ดึงดูดเกินจริง (Overpromise) ไม่ตรงกับ Landing Page/Offer จริง |

### เจาะลึกเพิ่ม: ทำไม CTR สูงไม่ได้แปลว่าคอปี้ดีเสมอไป

ข้อผิดพลาดที่พบบ่อยในการอ่านผล A/B Test คือการดู CTR อย่างเดียวแล้วสรุปว่าคอปี้นั้น "ดีที่สุด" — แต่ถ้าคอปี้สร้าง Curiosity Gap ที่เกินจริงจนคนคลิกเพราะอยากรู้ (ไม่ใช่เพราะสนใจซื้อจริง) จะได้ CTR สูงแต่ Conversion Rate หลังคลิกต่ำ ทำให้ Cost per Result สุดท้ายแพงกว่าคอปี้ที่ CTR ต่ำกว่าแต่ตรงกลุ่มเป้าหมายมากกว่า ต้องดู Metric ท้ายสุด (Cost per Result / ROAS) เป็นตัวตัดสินหลักเสมอ ไม่ใช่ Metric กลางทางอย่าง CTR เพียงอย่างเดียว

### ข้อผิดพลาดที่พบบ่อย

- ทดสอบหลายตัวแปรพร้อมกันในรอบเดียว (เปลี่ยนทั้ง Primary Text, Headline, ภาพพร้อมกัน) ทำให้ไม่รู้ว่าอะไรคือสาเหตุที่แท้จริงของผลต่าง
- ตัดสินผลเร็วเกินไปจาก Sample Size น้อย (ดูแค่ 200-300 Impression) ซึ่งมีความคลาดเคลื่อนทางสถิติสูง
- ใช้ CTR เป็นเกณฑ์ตัดสินเดียวโดยไม่ดู Cost per Result/Conversion Rate ที่ตามมา

## Step 380: Case Study Teardown — วิเคราะห์ Before/After คอปี้จริงแบบเจาะลึก

### บริบท: ธุรกิจคลินิกทำเล็บเจล ยิงแอด Lead Generation

**คอปี้ Before ที่ใช้อยู่เดิม:**
```
Primary Text:
คลินิก Nail Art Studio เปิดให้บริการทำเล็บเจล เล็บอะคริลิค
โดยช่างมืออาชีพ ประสบการณ์กว่า 10 ปี ใช้ผลิตภัณฑ์คุณภาพสูง
ปลอดภัย ไม่ทำร้ายเล็บ บริการดี ราคาไม่แพง
สนใจติดต่อสอบถามได้ที่เพจ

Headline: "คลินิก Nail Art Studio"
Description: (ว่าง)
CTA: Learn More
```

**ผลลัพธ์ก่อนปรับ:** CTR 0.7% Cost per Lead 180 บาท (สูงกว่าที่ธุรกิจกำหนดไว้ที่ 100 บาท)

### วิเคราะห์จุดอ่อนทีละ Field ตาม Checklist ที่เรียนมาทั้ง Part

**Primary Text:** เริ่มด้วยชื่อแบรนด์ (ผิดหลัก Step 372 — ไม่ควรเปิดด้วยแบรนด์) ไม่มี Hook ที่สร้าง Curiosity/Relevance ก่อน 125 ตัวอักษรแรก เนื้อหาเป็น Feature-dumping (ประสบการณ์ 10 ปี, ผลิตภัณฑ์คุณภาพสูง) ไม่มีการแปลงเป็น Benefit ตามหลัก FAB จาก Part 037 และ CTA ท้ายคอปี้อ่อนแอ ("สนใจติดต่อสอบถาม") ไม่มี Urgency หรือสิ่งที่จะได้รับชัดเจน ตามที่เรียนใน Step 369

**Headline:** เป็นเพียงชื่อแบรนด์ ไม่ใช่ Benefit-driven หรือ Curiosity-driven ตามหลัก Step 373 เสียโอกาสในการสื่อสารคุณค่าเพิ่มเติม

**Description:** เว้นว่างไว้ ทั้งที่สามารถใช้เสริม Trust Signal หรือเงื่อนไขโปรโมชั่นได้ตามหลัก Step 374

**CTA Button:** ใช้ "Learn More" ทั้งที่ Objective คือ Lead Generation ซึ่งควรใช้ "Sign Up" หรือ CTA ที่ตรงกับ Instant Form มากกว่า ตามหลัก Step 375

### คอปี้ After ที่ปรับตามหลักการทั้ง Part

```
Primary Text:
ทำเล็บเจลที่ไหนก็หลุดเร็ว ใช้ไม่ถึง 2 สัปดาห์ก็ต้องไปซ้ำใหม่?

หลายคนไม่รู้ว่าเล็บเจลที่หลุดเร็วส่วนใหญ่เกิดจากการเตรียมผิวเล็บ
ที่ไม่ได้มาตรฐาน ไม่ใช่เพราะเจลไม่ดี

Nail Art Studio ใช้เทคนิคเตรียมผิวเล็บ 5 ขั้นตอนก่อนลงเจล
ทำให้เล็บอยู่ทนนานขึ้นถึง 3-4 สัปดาห์โดยไม่หลุดล่อน
ลูกค้ากว่า 600 คนยืนยันผลลัพธ์นี้

จองวันนี้ รับส่วนลด 20% สำหรับลูกค้าใหม่ 30 ท่านแรกของเดือน
👉 กดจองเลย ก่อนคิวเต็ม

Headline: "เล็บเจลอยู่ทน 3-4 สัปดาห์ ไม่หลุดล่อน"
Description: "ส่วนลด 20% ลูกค้าใหม่ 30 ท่านแรก"
CTA: Sign Up (เชื่อมกับ Instant Form)
```

### ผลลัพธ์หลังปรับ

หลังปรับคอปี้ทั้งชุดตามหลักการที่เรียนมาทั้ง Part (Hook แบบ Relatable Problem, PAS Framework, FAB สำหรับแปลง Feature เป็น Benefit, Headline แบบ Ultra-specific, Description เสริม Trust/Urgency, CTA ที่ตรงกับ Objective) ผลลัพธ์ใน 14 วันถัดมา: CTR เพิ่มเป็น 2.1% Cost per Lead ลดลงเหลือ 78 บาท ต่ำกว่าเป้าที่ตั้งไว้ (100 บาท) เป็นครั้งแรก โดยไม่ได้เปลี่ยน Audience, Budget, หรือรูปภาพ/วิดีโอที่ใช้เลย — เปลี่ยนแค่คอปี้ทั้ง 4 Field ตามหลักการในบทนี้

### บทเรียนสำคัญจาก Teardown นี้

Case นี้แสดงให้เห็นว่าการปรับ "แค่คอปี้" โดยไม่แตะ Creative (ภาพ/วิดีโอ) หรือ Targeting เลย สามารถเปลี่ยนผลลัพธ์ได้อย่างมีนัยสำคัญ เพราะข้อผิดพลาดเดิมกระทบทุก Field พร้อมกัน (Primary Text อ่อนแอ, Headline ไม่มีคุณค่า, Description ว่างเปล่า, CTA ไม่ตรง Objective) — เมื่อแก้ทีละจุดตามหลักการที่ถูกต้อง ผลรวมของการแก้ไขทั้งหมดจึงส่งผลกระทบมากกว่าการแก้จุดเดียว

## Case Study: ร้านขายอุปกรณ์กีฬาออนไลน์ "SportGo" กับการเขียนคอปี้ 3 ระดับ Audience

**สถานการณ์เดิม:** SportGo ขายรองเท้าวิ่งผ่าน Facebook ใช้คอปี้ชุดเดียวกันทั้งแคมเปญ Cold Prospecting และ Retargeting เพราะทีมงานคิดว่า "เขียนคอปี้ดีตัวเดียวก็พอ ประหยัดเวลา" คอปี้ที่ใช้คือ:

```
"รองเท้าวิ่ง RunPro X รองรับแรงกระแทกดีเยี่ยม
เหมาะกับนักวิ่งทุกระดับ ราคา 2,990 บาท สั่งเลย!"
```

**ผลลัพธ์เดิม:** แคมเปญ Cold Prospecting ROAS 1.1 (ขาดทุน) แคมเปญ Retargeting ROAS 2.8 (พอใช้ได้) — ทีมงานสังเกตว่าทำไม Retargeting ดีกว่ามาก ทั้งที่ใช้คอปี้เดียวกัน

**การวิเคราะห์:** เมื่อทีมงานนำหลักการ Step 376 มาปรับ พบว่าคอปี้เดิมเหมาะกับ Retargeting Audience อยู่แล้วโดยไม่ได้ตั้งใจ (สั้น กระชับ เน้นราคา+ปิดขายทันที) แต่สำหรับ Cold Audience ที่ไม่รู้จักแบรนด์ RunPro เลย คอปี้นี้ไม่มีอะไรที่สร้าง Self-Recognition หรือ Relevance ทำให้ไม่มีเหตุผลจะสนใจ

**การปรับ:** ทีมงานเขียนคอปี้แยก 2 ชุดตาม Audience:

```
[Cold Audience — PAS + Relatable Problem]
วิ่งไป 3 กิโล แล้วเข่าเริ่มปวด? หลายคนคิดว่าเป็นเพราะ
ร่างกายไม่แข็งแรงพอ แต่จริงๆ อาจเป็นเพราะรองเท้าที่สวมอยู่
ไม่รองรับแรงกระแทกที่เหมาะกับน้ำหนักตัวคุณ

RunPro X ออกแบบพื้นรองเท้าดูดซับแรงกระแทก 3 ชั้น
ทดสอบโดยนักกายภาพบำบัดกีฬา ลดแรงกระทบที่เข่าได้ถึง 40%

👉 ดูรีวิวจากนักวิ่งกว่า 3,000 คนที่เปลี่ยนมาใช้ RunPro X

Headline: "ลดแรงกระแทกที่เข่าได้ถึง 40%"
CTA: Learn More

[Retargeting — 4U สั้น กระชับ]
RunPro X คู่ที่คุณดูไว้ เหลือสต็อกไม่ถึง 15 คู่
สั่งวันนี้ รับส่วนลด 10% ก่อนหมด

Headline: "ส่วนลด 10% เฉพาะวันนี้"
CTA: Shop Now
```

**ผลลัพธ์หลังแยกคอปี้ตาม Audience:** ROAS ของแคมเปญ Cold Prospecting เพิ่มจาก 1.1 เป็น 1.9 (เกือบเท่าตัว) ในขณะที่ Retargeting ยังคง ROAS 2.8-3.0 ใกล้เคียงเดิม (เพราะคอปี้เดิมเหมาะกับกลุ่มนี้อยู่แล้ว) การเปลี่ยนแปลงนี้พิสูจน์หลักการสำคัญที่สุดของ Part นี้ — คอปี้ที่ดีสำหรับ Audience หนึ่ง ไม่ได้แปลว่าดีสำหรับ Audience อื่นเสมอไป การแยกเขียนตาม Temperature คือสิ่งจำเป็น ไม่ใช่ Nice-to-have

## Checklist ท้ายบท

- [ ] เช็ค Preview ทุก Placement ก่อน Publish เพื่อดูว่าข้อความไม่ถูกตัดในจุดสำคัญ
- [ ] 125 ตัวอักษรแรกของ Primary Text มี Hook ที่สมบูรณ์ในตัว ไม่ต้องพึ่งส่วนที่ถูกตัด
- [ ] Headline เลือกแบบ Benefit-driven หรือ Curiosity-driven อย่างตั้งใจ ไม่ใช่สุ่มเขียน
- [ ] Description ไม่เว้นว่างโดยไม่มีเหตุผล ใช้เสริม Trust Signal/เงื่อนไขที่มีประโยชน์
- [ ] CTA Button ตรงกับ Objective และสิ่งที่คอปี้สัญญาไว้
- [ ] คอปี้แยกเขียนตาม Audience Temperature (Cold/Warm/Hot) ไม่ใช้ชุดเดียวกับทุกกลุ่ม
- [ ] ภาษาที่ใช้เป็นธรรมชาติแบบไทย ไม่แปลตรงจากอังกฤษ ไม่ Overclaim แบบสัมบูรณ์
- [ ] Emoji ใช้อย่างมีเหตุผล ไม่เกิน 1 ต่อประโยค ไม่รกจนอ่านยาก
- [ ] มีแผนการทดสอบ A/B ตัวแปรคอปี้อย่างเป็นระบบ ทีละตัวแปร ไม่เปลี่ยนพร้อมกันหลายอย่าง
- [ ] ตัดสินผลคอปี้จาก Cost per Result/ROAS ไม่ใช่ CTR อย่างเดียว

## Workshop / แบบฝึกหัด

**เป้าหมาย:** เขียนชุดคอปี้ (Primary Text + Headline + Description + CTA) ให้กับสินค้าเดียวกัน (ใช้สินค้าเดิมจาก Workshop ใน Part 036-037 เพื่อความต่อเนื่อง) แยกตาม 3 ระดับ Audience Temperature

**ขั้นตอนที่ 1 — กำหนด Custom Audience สมมติ 3 กลุ่ม (10 นาที)**
เขียนอธิบายสั้นๆ ว่า Cold Audience ของสินค้านี้คือใคร (ไม่รู้จักแบรนด์เลย), Warm Audience คือใคร (เคย Engage/เข้าเว็บแล้ว), Hot Audience คือใคร (ลูกค้าเก่า/เพิ่งดู Landing Page)

**ขั้นตอนที่ 2 — เขียนชุดคอปี้สำหรับ Cold Audience (20 นาที)**
เขียน Primary Text (ใช้ PAS หรือ AIDA เต็มรูปแบบ), Headline, Description, และเลือก CTA Button ที่เหมาะสม ตรวจสอบด้วย Copy-Review Checklist จาก Part 037

**ขั้นตอนที่ 3 — เขียนชุดคอปี้สำหรับ Warm Audience (15 นาที)**
เขียนชุดคอปี้ที่สั้นกว่า เน้น Social Proof และแก้ Objection หลัก 1-2 ข้อ พร้อม Headline/Description/CTA ของตัวเอง

**ขั้นตอนที่ 4 — เขียนชุดคอปี้สำหรับ Hot Audience/Retargeting (10 นาที)**
เขียนคอปี้สั้นที่สุดในทั้ง 3 ชุด เน้น Urgency และข้อเสนอเฉพาะ พร้อม Headline/Description/CTA

**ขั้นตอนที่ 5 — ทำ Preview Check และ Localization Check (10 นาที)**
ตรวจทั้ง 3 ชุดคอปี้ว่า 125 ตัวอักษรแรกของ Primary Text สื่อความสมบูรณ์หรือไม่ (โดยการนับตัวอักษรจริงหรือใช้เครื่องมือนับคำ) และตรวจว่าไม่มีภาษาที่ดูเป็นสแปมหรือแปลจากอังกฤษตรงตัวตามหลัก Step 377

**ขั้นตอนที่ 6 — วางแผนการทดสอบ A/B (10 นาที)**
เลือกชุดคอปี้ 1 ชุด (เช่น Cold Audience) มาวางแผนว่าจะทดสอบตัวแปรไหนก่อน (Primary Text/Headline/CTA) และจะใช้เกณฑ์ Metric อะไรตัดสินผล ตามหลักการ Step 379

**ผลลัพธ์ที่ควรได้จาก Workshop นี้:** ชุดคอปี้สมบูรณ์ 3 ชุด (Cold, Warm, Hot) พร้อม Headline, Description, CTA ของแต่ละชุด และแผนการทดสอบ A/B ที่พร้อมนำไปใช้สร้าง Ad จริงใน Ads Manager ทันที

## สรุปและเชื่อมไปยัง Part ถัดไป

Part นี้ปิดท้ายพื้นฐานคอปีไรติ้งของ Section D ด้วยการนำความรู้เรื่อง Hook (Part 036) และ Framework การโน้มน้าวใจ (Part 037) มาประกอบเป็นชุดคอปี้ที่ใช้งานได้จริงใน Ads Manager — ครอบคลุมกฎการตัดข้อความในแต่ละ Placement, การจัดโครงสร้าง Primary Text ให้คนกด See More, การเลือก Headline และ CTA ให้เหมาะสม, การเขียนต่างกันตาม Audience Temperature, หลักภาษาไทยที่ Convert จริง, การใช้ Emoji อย่างมีชั้นเชิง, และวิธี A/B Testing คอปี้อย่างเป็นระบบ

ถึงจุดนี้คุณมีทั้งความเข้าใจเรื่อง Hook และคอปี้แบบเต็มรูปแบบแล้ว แต่คอปี้ที่ดีที่สุดในโลกก็จะไม่มีความหมายถ้าไม่มีภาพหรือวิดีโอที่สนับสนุนมันอย่างเหมาะสม Part ถัดไป (Part 039) จะพาไปเรียนรู้ **การถ่ายภาพและดีไซน์ภาพโฆษณาที่ Convert** — องค์ประกอบภาพ, สี, Composition, และหลักการออกแบบที่ทำงานร่วมกับคอปี้ที่เราเขียนไว้ให้ได้ผลลัพธ์สูงสุด ก่อนจะไปเรียนเรื่อง Video Production ใน Part 040 และ UGC Content ใน Part 041 ตามลำดับ
