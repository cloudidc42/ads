## Step 201: เปิด Ads Manager และทำความรู้จักหน้าจอหลักทั้งหมดก่อนเริ่มสร้างแคมเปญ

### เข้า Ads Manager ได้กี่ทาง

วิธีที่แนะนำที่สุดคือเข้าผ่าน URL ตรง `business.facebook.com/adsmanager` หรือ `adsmanager.facebook.com` เพราะจะพาคุณเข้าสู่บัญชีโฆษณาที่ผูกกับ Business Manager ทันที ไม่ต้องผ่านเมนูอ้อมของ Facebook ส่วนตัว

ทางเลือกอื่น:
- จากหน้า Facebook ส่วนตัว → เมนูซ้าย (หรือปุ่ม hamburger ☰ บนมือถือ) → เลื่อนหา "Ads Manager" ใต้หมวด "Advertise"
- จาก Meta Business Suite → เมนูซ้าย "All tools" → หมวด "Advertise" → "Ads Manager"
- จากแถบ Bookmark หลังจากปักหมุดไว้ครั้งแรก (แนะนำให้ปักหมุดเพราะคุณจะเข้าหน้านี้ทุกวัน)

### ตรวจสอบว่าอยู่ใน Ad Account ที่ถูกต้อง

มุมบนซ้ายของหน้า Ads Manager จะมี Dropdown แสดงชื่อ Ad Account ปัจจุบัน คลิกเพื่อดูรายการ Ad Account ทั้งหมดที่คุณมีสิทธิ์เข้าถึง (ถ้าคุณดูแลหลายลูกค้า อาจมีสิบกว่าบัญชี) **นี่คือจุดที่มือใหม่พลาดบ่อยที่สุด** — สร้างแคมเปญผิด Ad Account เช่น ตั้งใจจะยิงให้ลูกค้า A แต่ดันไปสร้างในบัญชีของลูกค้า B เพราะไม่ได้เช็ค Dropdown ก่อน

วิธีป้องกัน: ตั้งเป็นสูตรนิสัยว่า **ทุกครั้งก่อนกดปุ่ม "Create"** ให้มองชื่อ Ad Account มุมบนซ้ายก่อน 1 วินาทีเสมอ

### ส่วนประกอบหลักของหน้าจอ Ads Manager

แถบเมนูด้านซ้าย (Column ซ้าย) แบ่งเป็น 3 ระดับตามลำดับชั้น:
- **Campaigns** (แคมเปญ) — ระดับบนสุด ตั้งค่า Objective และ Budget (ถ้าเปิด CBO)
- **Ad sets** (ชุดโฆษณา) — ระดับกลาง ตั้งค่า Audience, Placement, Budget (ถ้าไม่ใช้ CBO), Schedule
- **Ads** (โฆษณา) — ระดับล่างสุด ตั้งค่า Creative จริงที่คนเห็น

แถบด้านบนมี:
- ปุ่ม **"+ Create"** สีเขียว — จุดเริ่มสร้างแคมเปญใหม่ทุกครั้ง
- **Filters** — กรองแคมเปญตามสถานะ, Objective, ชื่อ
- **Columns** dropdown — เลือกว่าจะแสดง Metric คอลัมน์ไหนในตาราง (จะสอนละเอียดใน Section F)
- **Breakdown** — แยกผลลัพธ์ตาม Age, Gender, Placement, Region ฯลฯ
- **Reports** — Export ข้อมูลเป็น Excel/CSV

ตรงกลางจอคือ **ตารางข้อมูล** แสดงรายการ Campaign/Ad Set/Ad พร้อม Toggle เปิด-ปิด (ปุ่มสีเขียว/เทาด้านซ้ายของแต่ละแถว) และตัวเลข Metric เช่น Results, Reach, Impressions, Cost per Result, Amount Spent

### สิ่งที่ต้องเช็คก่อนเริ่มสร้างแคมเปญทุกครั้ง (Pre-flight Check)

1. Ad Account ถูกต้อง (ตามที่บอกไปข้างบน)
2. Payment Method active อยู่ ไม่มี Error สีแดงเตือนเรื่องบัตร/การเงิน (เช็คที่ Billing ใน Business Settings)
3. Pixel ติดตั้งและ Active แล้ว (เช็คที่ Events Manager ตามที่เรียนใน Part 013–015) — ถึงแม้แคมเปญ Awareness จะไม่ต้องพึ่ง Pixel มาก แต่ควรติดไว้ตั้งแต่แคมเปญแรกเพื่อเก็บข้อมูลสร้าง Custom Audience ในอนาคต
4. Facebook Page ที่จะใช้ยิงแอด published แล้ว ไม่ใช่ Draft
5. รู้เป้าหมายของแคมเปญนี้ชัดเจน (ทำตาม Goal Sheet จาก Part 004) ก่อนกดปุ่ม Create เพราะ Objective ที่เลือกจะกำหนดทุกอย่างที่ตามมา

### ข้อผิดพลาดที่พบบ่อย

- เปิดหลาย Tab ของ Ads Manager พร้อมกันแล้วสร้าง/แก้ไขแคมเปญคนละ Tab พร้อมกัน ทำให้ข้อมูล conflict กันและบางครั้ง Save ไม่ติด
- ใช้เบราว์เซอร์ที่มี Extension บล็อก Ad/Tracker (เช่น uBlock Origin) รบกวนการโหลดหน้า Ads Manager บางส่วน ทำให้กราฟหรือปุ่มบางอันไม่ขึ้น — แนะนำให้มี Browser Profile แยกสำหรับงานแอดโดยเฉพาะ ไม่ลง Extension บล็อกโฆษณา (ตามที่เรียนใน Part 006)
- ไม่ปักหมุด (Pin) Ads Manager ทำให้ทุกครั้งต้องหาทางเข้าใหม่ เสียเวลา

### เจาะลึกเพิ่ม: มุมมองการแสดงผลแบบ Column View vs Card View

Ads Manager มี 2 มุมมองหลักในการดูตารางแคมเปญ:

- **Column View** (ค่า Default) — แสดงเป็นตารางแถว/คอลัมน์ เหมาะกับการเทียบตัวเลขหลายแคมเปญพร้อมกัน
- **Reporting View** — เข้าถึงผ่านปุ่ม "Reports" มุมบนขวา ให้สร้างกราฟเปรียบเทียบ Metric ข้ามช่วงเวลา เหมาะกับการทำ Client Report (จะเรียนลึกใน Part 091)

นอกจากนี้ยังมี **Mobile App "Meta Ads Manager"** ที่แยกจากเว็บ ใช้สำหรับเช็คสถานะด่วนระหว่างวัน (เปิด/ปิด Ad Set, ดู Amount Spent) แต่ **ไม่แนะนำให้สร้างแคมเปญใหม่จากมือถือ** เพราะ Field การตั้งค่าบางส่วน (เช่น Detailed Targeting แบบละเอียด, Advanced Advantage+ Options) จะถูกย่อ/ซ่อนไปเมื่อเทียบกับเวอร์ชันเว็บ ทำให้ตั้งค่าไม่ครบถ้วน ให้ใช้มือถือเป็นเครื่องมือ "มอนิเตอร์" เท่านั้น ส่วนการสร้าง/แก้ไขโครงสร้างแคมเปญให้ทำบนคอมพิวเตอร์เสมอ

### เจาะลึกเพิ่ม: Keyboard และการนำทางที่ช่วยประหยัดเวลา

เมื่อทำงานกับหลายแคมเปญทุกวัน ควรฝึกใช้ทางลัดเหล่านี้:
- คลิกขวาที่แถวแคมเปญ → "Duplicate" เพื่อสร้างสำเนาแทนการสร้างใหม่ทุกครั้ง (จะเรียนละเอียดใน Part 016 Step 158)
- ใช้ช่อง Search มุมบนของตาราง พิมพ์คำในชื่อแคมเปญเพื่อ Filter แทนการเลื่อนหาด้วยตา
- ปักหมุด (Star ⭐) แคมเปญที่ Monitor บ่อยไว้ด้านบนสุดของรายการ

## Step 202: เลือก Campaign Objective — Awareness เจาะลึก (Brand Awareness vs Reach) และ Buying Type

### กดปุ่ม Create

คลิกปุ่มเขียว **"+ Create"** มุมบนซ้ายของตาราง Campaigns จะเปิด Modal ให้เลือก **Buying type** ก่อนเสมอ:

- **Auction** (การประมูล) — ตัวเลือกมาตรฐานที่ใช้ 99% ของทุกแคมเปญ ระบบจะประมูลแข่งกับผู้ลงโฆษณาคนอื่นแบบ Real-time ทุกครั้งที่มีโอกาสแสดงโฆษณา (Ad Impression Opportunity)
- **Reservation** — จองพื้นที่โฆษณาล่วงหน้าแบบ Fixed CPM รับประกัน Reach บอกได้แน่นอนว่าจะเห็นกี่คน เหมาะกับแบรนด์ใหญ่ที่มีงบเยอะและต้องการ Guaranteed Delivery (เช่น เปิดตัวสินค้าระดับประเทศ) ไม่เหมาะกับมือใหม่หรือ SME เพราะงบขั้นต่ำสูงมากและไม่มี Machine Learning มาช่วย Optimize

สำหรับหลักสูตรนี้และธุรกิจส่วนใหญ่ ให้เลือก **Auction** เสมอ แล้วกด Continue

### เลือก Objective

หน้าถัดไปจะโชว์ 6 Objective หลัก (ตามที่เรียนละเอียดใน Part 017):

1. Awareness
2. Traffic
3. Engagement
4. Leads
5. App promotion
6. Sales

คลิกเลือก **"Awareness"**

### Awareness แบ่งเป็น 2 Performance Goal

หลังเลือก Awareness ระบบจะให้เลือกต่อว่าจะ Optimize เพื่ออะไร ภายใต้ Ad Set (บางเวอร์ชัน UI จะให้เลือกตรงนี้เลยในหน้า Campaign) — สองตัวเลือกหลักคือ:

**1. Brand Awareness (การรับรู้ถึงแบรนด์)**
- Optimization Goal: **Ad Recall Lift** — ระบบพยายามหาคนที่ "มีโอกาสจะจดจำโฆษณาคุณได้มากที่สุด" ถ้าถูกถามอีก 2 วันข้างหน้า
- ใช้ Model การทำนายภายในของ Meta (Estimated Ad Recall Lift Rate) ไม่ใช่ Metric ที่วัดตรงได้ 100% แต่เป็นค่าประมาณจาก Survey Model
- เหมาะกับ: แบรนด์ใหม่ที่อยากให้คนจดจำชื่อ, สินค้าที่ต้อง build Brand ก่อนขาย (เช่น เปิดร้านใหม่ในพื้นที่, Personal Branding)

**2. Reach (การเข้าถึง)**
- Optimization Goal: **Reach** — ระบบพยายามแสดงโฆษณาให้ **คนที่ไม่ซ้ำกัน (Unique Users)** มากที่สุดเท่าที่งบจะครอบคลุมได้ โดยจำกัด Frequency ไม่ให้คนเดิมเห็นถี่เกินไป
- มี Feature เสริมคือ **Frequency Cap** — กำหนดได้ว่าไม่อยากให้คนเห็นเกินกี่ครั้งต่อกี่วัน (เช่น ไม่เกิน 2 ครั้ง ต่อ 7 วัน) เหมาะกับแคมเปญที่อยากกระจายให้กว้างที่สุดโดยไม่ยิงซ้ำคนเดิมจนน่ารำคาญ
- เหมาะกับ: การประกาศข่าวสำคัญ (เปิดสาขาใหม่, Event, โปรโมชั่นใหญ่), แคมเปญที่อยาก "คลุมพื้นที่" ให้ได้คนมากที่สุดในงบจำกัด

### เลือกอันไหนดีสำหรับแคมเปญแรก

สำหรับมือใหม่ที่กำลังฝึกมือ แนะนำเริ่มที่ **Reach** ก่อน เพราะ:
- Metric อ่านง่ายกว่า (Reach, Frequency, CPM เข้าใจตรงไปตรงมา)
- ไม่ต้องพึ่ง Model การทำนายซับซ้อนแบบ Ad Recall
- ควบคุม Frequency Cap ได้ ทำให้เห็นผลกระทบของการตั้งค่าชัดเจน

ถ้าธุรกิจของคุณมีแผน Brand Building จริงจังและมีงบสูงพอ (หลักหมื่นบาทขึ้นไปต่อเดือนสำหรับ Awareness อย่างเดียว) ค่อยลองสวิตช์ไป Brand Awareness ในแคมเปญถัดไปเพื่อเปรียบเทียบ

### ตั้งชื่อ Campaign และเปิด/ปิด Advantage+ Campaign Budget

ก่อนกด Continue ไปหน้า Ad Set ให้สังเกต 2 อย่างในหน้า Campaign:

1. **ช่องชื่อ Campaign** — อยู่บนสุด (จะสอนสูตรตั้งชื่อละเอียดใน Step 203)
2. **Toggle "Advantage+ campaign budget" (แต่ก่อนเรียกว่า Campaign Budget Optimization / CBO)** — ถ้าเปิด ระบบจะบริหารงบให้ทั่วทุก Ad Set ในแคมเปญนี้อัตโนมัติ (เหมาะกับแคมเปญที่มีหลาย Ad Set) สำหรับแคมเปญแรกที่มี Ad Set เดียว **แนะนำปิด Toggle นี้ไว้ก่อน** แล้วไปตั้ง Budget ที่ระดับ Ad Set แทน เพื่อให้เห็นภาพชัดว่า Budget ผูกกับอะไร (จะเรียนเจาะลึก CBO vs ABO ใน Part 018 ไปแล้ว และจะกลับมาเจาะลึกอีกใน Part 059)

### ข้อผิดพลาดที่พบบ่อย

- เลือก "Engagement" เพราะเห็นคำว่า "การมีส่วนร่วม" ฟังดูดี ทั้งที่จริงต้องการแค่ให้คนรู้จักแบรนด์ — Objective คนละความหมาย ต้องเลือกตาม Performance Goal ที่ต้องการจริง ไม่ใช่ตามชื่อที่ฟังดูดี
- เปิด Advantage+ Campaign Budget ทั้งที่มี Ad Set เดียว ทำให้งงว่า Budget หายไปไหนเวลาไปดูที่ระดับ Ad Set
- ลืมว่าเลือก Objective ผิดแล้วพยายามไปแก้ทีหลัง — **ความจริงคือ Objective ระดับ Campaign แก้ไม่ได้หลัง Publish** ต้องสร้างแคมเปญใหม่เท่านั้น จึงต้องมั่นใจตั้งแต่ตอนเลือก

### เจาะลึกเพิ่ม: Ad Recall Lift คำนวณมาจากไหน

Estimated Ad Recall Lift Rate ไม่ได้มาจากการถามผู้ใช้ทุกคนจริงๆ (นั่นคือ Brand Lift Survey ซึ่งเป็นเครื่องมือแยกที่ใช้กับแคมเปญงบสูงเท่านั้น) แต่ Meta ใช้ **Model การถดถอย (Regression Model)** ที่ผ่านการเทรนจากผลสำรวจจริงหลายพันแคมเปญในอดีต มาทำนายว่า "คนกลุ่มนี้ ในบริบทโฆษณาแบบนี้ มีโอกาสจดจำได้กี่เปอร์เซ็นต์" โดยพิจารณาปัจจัยเช่น ตำแหน่งที่แสดง (Placement), ความยาวที่คนดูวิดีโอ, จำนวนครั้งที่เห็น (Frequency) เทียบกับ Baseline ของคนที่ไม่เห็นโฆษณาเลย ตัวเลขนี้เหมาะกับการ "เทียบระหว่าง Ad Set ภายในแคมเปญเดียวกัน" มากกว่าจะเอาไปเทียบข้ามอุตสาหกรรมหรือข้ามบัญชี

### เจาะลึกเพิ่ม: ตารางเทียบ Reach vs Brand Awareness แบบสรุป

| ประเด็น | Reach | Brand Awareness |
|---|---|---|
| Optimize เพื่อ | คนไม่ซ้ำมากที่สุด | โอกาสจดจำแบรนด์สูงสุด |
| Metric หลักที่ดู | Reach, Frequency, CPM | Estimated Ad Recall Lift, Cost per Estimated Ad Recall Lift |
| ควบคุม Frequency ได้ | ได้ (Frequency Cap) | ไม่ได้ตรงๆ (ระบบเลือกให้เอง) |
| เหมาะกับงบ | เริ่มต้นได้แม้งบไม่สูง | แนะนำงบสูงกว่าเพื่อให้ Model ทำงานแม่นยำ |
| เหมาะกับมือใหม่ | เหมาะมาก (อ่านผลง่าย) | เหมาะกับขั้นถัดไปหลังคุ้นมือ |

## Step 203: Naming Convention มาตรฐานสำหรับ Campaign / Ad Set / Ad

Naming Convention คือ "ระบบการตั้งชื่อ" ที่ทำให้คุณและทีมมองชื่อแคมเปญ 1 บรรทัดแล้วรู้ทันทีว่านี่คือแคมเปญอะไร ยิงให้ใคร งบเท่าไหร่ ทดสอบอะไร — สำคัญมากเมื่อบัญชีโฆษณามีแคมเปญเป็นสิบเป็นร้อยรายการ (ซึ่งจะเกิดขึ้นแน่นอนถ้าคุณทำงานนี้ต่อเนื่องเกิน 3 เดือน)

### สูตร Naming ระดับ Campaign

```
[วันที่]_[Objective]_[กลุ่มเป้าหมาย/Product]_[หมายเลข Version]
```

ตัวอย่างจริง:
```
250926_AWR_แบรนด์ใหม่ทั้งหมด_V1
250926_AWR_เปิดสาขาลาดพร้าว_V1
```

โดย `250926` คือปี-เดือน-วัน แบบย่อ (26 กันยายน 2025) เรียงจากใหญ่ไปเล็กเพื่อให้ Sort ตามตัวอักษรแล้วเรียงตามวันที่ได้อัตโนมัติ, `AWR` คือย่อของ Awareness (จะใช้รหัสย่อ Objective สอดคล้องกันตลอดทั้งบัญชี เช่น `TRF` = Traffic, `ENG` = Engagement, `LEAD` = Leads, `CONV` = Conversion, `CAT` = Catalog)

### สูตร Naming ระดับ Ad Set

```
[Audience Type]_[Age/Gender ถ้ามี]_[Placement]_[Budget]
```

ตัวอย่าง:
```
Interest_ความสวยความงาม_25-45F_AutoPlacement_300THB
Lookalike1%_ลูกค้าเก่า_18-54All_AutoPlacement_500THB
```

### สูตร Naming ระดับ Ad

```
[Format]_[Concept/Hook สั้นๆ]_[Version ครีเอทีฟ]
```

ตัวอย่าง:
```
Video_Hookปัญหาสิว_V1
Image_ก่อนหลัง_V2
Carousel_4สินค้าขายดี_V1
```

### ตัวอย่างเต็มระบบ 3 ชั้น

```
Campaign:  250926_AWR_เปิดสาขาลาดพร้าว_V1
  Ad Set:  Interest_คนรักกาแฟ_25-45All_AutoPlacement_400THB
    Ad:    Video_เปิดสาขาใหม่Hook3วิ_V1
    Ad:    Image_โปรโมชั่นเปิดร้าน_V1
```

เมื่อคุณเปิดตารางแคมเปญ 50 แถว แต่ตั้งชื่อระบบนี้เหมือนกันหมด คุณจะกวาดตาดูแล้วรู้ทันทีว่าอันไหนคือแคมเปญอะไร ทดสอบอะไรอยู่ ไม่ต้องเปิดเข้าไปดูรายละเอียดทุกอัน

### กฎเหล็ก 5 ข้อของ Naming Convention ที่ดี

1. **สม่ำเสมอ** — ใช้รูปแบบเดียวกันทุกแคมเปญตลอดไป ห้ามเปลี่ยนสูตรกลางทาง
2. **สั้นแต่ครบข้อมูลสำคัญ** — ไม่ต้องยาวเป็นประโยค แต่ต้องมีข้อมูลที่จำเป็นในการตัดสินใจ
3. **ไม่ใช้ภาษาที่กำกวม** — เช่น "Test1", "ลองดู", "แคมเปญใหม่" (อ่านซ้ำอีก 2 เดือนแล้วจะไม่รู้ว่าคืออะไร)
4. **แยกด้วยเครื่องหมายคงที่** — เลือก `_` หรือ `-` แบบเดียวแล้วใช้ตลอด ไม่ผสมกัน
5. **เขียนสูตรนี้เก็บไว้ใน Google Doc/Sheet ของทีม** — ให้ทุกคนในทีม (รวมลูกค้าที่เข้ามาดู Ads Manager) เข้าใจตรงกัน

### ทำไม Naming Convention สำคัญกว่าที่คิด

เมื่อบัญชีโตขึ้น การใช้ **Filter** และ **Breakdown** ใน Ads Manager จะพึ่งพาชื่อแคมเปญเป็นหลักในการค้นหา ถ้าคุณอยาก Filter ดูเฉพาะแคมเปญ Objective Awareness ทั้งหมดในเดือนกันยายน คุณจะพิมพ์ `250909` ใน Search box แล้วเจอทุกแคมเปญที่สร้างวันนั้นทันที หรือถ้าอยากดูเฉพาะ Objective Traffic ทั้งหมด ก็พิมพ์ `TRF` ในกล่องค้นหาได้เลย — นี่คือพลังของ Naming Convention ที่ดี

### ข้อผิดพลาดที่พบบ่อย

- ปล่อยให้ระบบตั้งชื่อ Default ให้ (เช่น "Awareness Campaign" เฉยๆ) — พอมีแคมเปญที่ 5 จะแยกไม่ออกว่าอันไหนคืออันไหน
- ใส่ชื่อลูกค้าเป็นภาษาที่สับสนกับ Policy Sensitive Category (เช่น ใส่ชื่อโรคในชื่อแคมเปญของคลินิก) แม้ Meta จะไม่ตรวจ Policy จากชื่อแคมเปญ แต่ถ้าลูกค้าหลายคนแชร์ Business Manager ร่วมกัน ชื่อที่ Sensitive อาจถูกคนอื่นเห็นได้ ควรระวังเรื่อง Privacy
- ตั้งชื่อยาวเกินไปจนตารางใน Ads Manager แสดงผลไม่ครบ ต้อง Hover ทุกครั้งเพื่ออ่าน

### เจาะลึกเพิ่ม: ตัวย่อ Objective มาตรฐานที่แนะนำให้ใช้ตลอดหลักสูตรนี้

เพื่อให้สอดคล้องกันทั้งบัญชี แนะนำตารางตัวย่อนี้ (ปรับใช้ได้ตามสไตล์ทีมของคุณ แต่เมื่อเลือกแล้วห้ามเปลี่ยน):

| Objective | ตัวย่อ |
|---|---|
| Awareness (Reach) | AWR |
| Awareness (Brand Awareness) | BAW |
| Traffic | TRF |
| Engagement | ENG |
| Video Views | VDV |
| Leads | LEAD |
| Messages | MSG |
| Sales (Conversion) | CONV |
| Catalog Sales | CAT |
| App Promotion | APP |

### เจาะลึกเพิ่ม: การใส่ Version (V1, V2, …) มีประโยชน์อย่างไร

เลข Version ไม่ใช่แค่ "เลขลำดับ" แต่ควรสื่อว่าเป็นการเปลี่ยนแปลงระดับไหน — แนะนำกฎง่ายๆ ว่า:
- เปลี่ยน **Audience** หลัก → เพิ่ม Version ที่ระดับ Campaign หรือ Ad Set (เช่น V1 → V2)
- เปลี่ยนแค่ **Creative** ภายใน Ad Set เดิม → เพิ่ม Version ที่ระดับ Ad เท่านั้น ไม่ต้องเปลี่ยนที่ Campaign/Ad Set
- Duplicate เพื่อทดสอบ A/B → ใส่ตัวอักษรบอกกลุ่มทดสอบ เช่น `_TestA` / `_TestB` ต่อท้าย Version

วิธีนี้ทำให้เมื่อมองประวัติแคมเปญย้อนหลัง จะรู้ทันทีว่า "จุดที่เปลี่ยนคืออะไร" โดยไม่ต้องเปิดเข้าไปดูรายละเอียดทุกอัน ซึ่งเป็นพื้นฐานสำคัญของการทำ Creative Testing Framework ที่จะเรียนเจาะลึกใน Part 044

## Step 204: ตั้งค่า Ad Set — Audience พื้นฐาน (Location, Age, Gender, Detailed Targeting, Languages)

หลังกด Continue จากหน้า Campaign คุณจะเข้าสู่หน้า **Ad Set** ส่วนแรกที่เจอคือ **Audience** (บางเวอร์ชัน UI เรียกรวมว่า "Advantage+ Audience" — ถ้าเปิด Toggle นี้ ระบบจะให้ Meta AI เลือกกลุ่มเป้าหมายกว้างๆ เองโดยอิงจากสัญญาณที่คุณให้ไว้เพียงเล็กน้อย เราจะเรียนเรื่องนี้ลึกใน Part 030 — สำหรับแคมเปญแรกนี้ **แนะนำปิด Advantage+ Audience** และตั้งค่าเองแบบ Manual เพื่อให้เข้าใจกลไกพื้นฐานก่อน)

### Location (ตำแหน่งที่ตั้ง)

Field แรกคือ **"Locations"** ให้พิมพ์ชื่อประเทศ/จังหวัด/เขต/รหัสไปรษณีย์ที่ต้องการยิง มีตัวเลือกย่อย:

- **Everyone in this location** — ทุกคนที่อยู่ในพื้นที่นี้ (รวมทั้งคนที่พักอาศัยและคนที่กำลังเดินทางผ่าน)
- **People who live in this location** — เฉพาะคนที่ Facebook ระบุว่า "อาศัยอยู่จริง" ในพื้นที่นี้ (ใช้ Location History ระยะยาว) เหมาะกับธุรกิจหน้าร้านที่อยากยิงเฉพาะคนในพื้นที่จริงๆ ไม่ใช่นักท่องเที่ยว
- **People recently in this location** — คนที่เพิ่งอยู่ในพื้นที่นี้ช่วงไม่นานมานี้ เหมาะกับ Event หรือโปรโมชั่นระยะสั้น
- **People traveling in this location** — เฉพาะคนที่กำลังเดินทาง ไม่ใช่คนอาศัยประจำ (เหมาะกับสนามบิน, สถานที่ท่องเที่ยว)

สามารถพิมพ์เพิ่มได้หลายพื้นที่ และมีปุ่ม **"Drop Pin"** ให้กำหนดรัศมี (Radius) รอบจุดที่ปักหมุด เช่น ปักหมุดที่หน้าร้านแล้วเลือกรัศมี 1–80 กิโลเมตร เหมาะมากสำหรับธุรกิจหน้าร้าน/คลินิก/ร้านอาหารที่ต้องการยิงเฉพาะคนในระยะที่เดินทางมาซื้อได้จริง

### Age และ Gender

- **Age** — Slider เลือกช่วงอายุ 13–65+ ค่า Default คือ 18–65+ อย่าเผลอปล่อย Default ถ้าสินค้าคุณมีกลุ่มเป้าหมายเฉพาะ (เช่น สินค้าสำหรับวัยทำงานควรตั้ง 25–45 ไม่ใช่ 18–65+ ทั้งหมด เพราะจะเปลืองงบไปกับกลุ่มที่ไม่ใช่ลูกค้า)
- **Gender** — All, Men, Women เลือก All เป็นค่าเริ่มต้นถ้าไม่แน่ใจ แล้วดู Breakdown by Gender ทีหลังว่าเพศไหน Convert ดีกว่าค่อยไปเจาะเฉพาะในแคมเปญถัดไป (อย่าเดาเองจากความรู้สึกว่า "สินค้านี้ผู้หญิงต้องซื้อแน่ๆ" เพราะข้อมูลจริงอาจสวนทาง)

### Detailed Targeting (การกำหนดกลุ่มเป้าหมายแบบละเอียด)

ช่องนี้ให้พิมพ์ **Interests** (ความสนใจ), **Behaviors** (พฤติกรรม), หรือ **Demographics** (ข้อมูลประชากรเพิ่มเติมเช่น การศึกษา, สถานะความสัมพันธ์, งาน) ระบบจะ Suggest คำที่เกี่ยวข้องขึ้นมาให้เลือกทันทีที่พิมพ์

ตัวอย่างการค้นหา: พิมพ์ "กาแฟ" ระบบจะโชว์ตัวเลือกเช่น "Coffee" (Interest), "Coffeehouses" (Interest), "Small business owners" (Behavior) ฯลฯ พร้อมตัวเลข **Audience Size** โดยประมาณด้านข้าง

ปุ่ม **"Narrow Audience"** (แคบกลุ่มเป้าหมายลง) ให้กดเพื่อเพิ่มเงื่อนไข "AND" — เช่น สนใจกาแฟ **และ** สนใจสุขภาพ (ต้องเข้าเงื่อนไขทั้งสองอย่าง Audience จะเล็กลงมาก) ตรงข้ามกับการพิมพ์เพิ่มในช่องเดิมซึ่งเป็นเงื่อนไข "OR" (สนใจกาแฟ หรือ สนใจชา อย่างใดอย่างหนึ่งก็เข้าเงื่อนไข)

### Languages

ปกติเว้นว่างไว้ (หมายถึงทุกภาษา) ยกเว้นกรณีต้องการยิงเฉพาะคนที่ตั้งค่าภาษา Facebook เป็นภาษาใดภาษาหนึ่งโดยเฉพาะ เช่น ธุรกิจที่ขายสินค้าให้คนไทยที่อยู่ต่างประเทศ อาจตั้งภาษาเป็น "Thai" เพื่อกรองให้แม่นขึ้น

### Audience Size Meter

ด้านขวาของหน้าจอจะมี Gauge แสดง **Audience Size** (ขนาดกลุ่มเป้าหมายที่เข้าเงื่อนไข) พร้อมแถบสี บอกว่ากลุ่มนี้ "Specific" (แคบ), "Broad" (กว้าง) หรืออยู่กลางๆ — ตัวเลขนี้เป็นเพียง **Estimate** ไม่ใช่การันตีว่าจะเข้าถึงได้เท่านั้น ให้ใช้เป็นแนวทางประกอบการตัดสินใจ ไม่ใช่ตัวชี้วัดหลักในการเลือก Audience

สำหรับแคมเปญ Awareness งบไม่สูง แนะนำ Audience Size อยู่ที่ประมาณ **500,000 – 2,000,000 คน** ในประเทศไทย ถ้าแคบกว่านี้มากๆ (เช่น หลักหมื่น) ระบบจะหาคนแสดงโฆษณายากและ CPM จะพุ่งสูง

### ข้อผิดพลาดที่พบบ่อย

- ตั้ง Detailed Targeting แคบเกินไปตั้งแต่แคมเปญแรก (ซ้อน Narrow Audience 3–4 ชั้น) ทำให้กลุ่มเป้าหมายเหลือหลักพันคน ระบบหาคนแสดงยาก CPM พุ่ง
- ลืมปรับ Age Range จาก Default 18–65+ ทั้งที่สินค้ามีกลุ่มเป้าหมายชัดเจน
- ใช้ Location แบบ "Everyone in this location" สำหรับธุรกิจหน้าร้านที่ต้องการเฉพาะคนพื้นที่จริง ทำให้ยิงโฆษณาไปถึงนักท่องเที่ยวที่ไม่ได้อยู่ถาวรในพื้นที่

### เจาะลึกเพิ่ม: Special Ad Category — Checkbox ที่ห้ามมองข้าม

เหนือส่วน Audience จะมี Checkbox **"Special Ad Category"** ให้ประกาศว่าแคมเปญนี้เกี่ยวข้องกับหมวด Housing (ที่อยู่อาศัย), Employment (การจ้างงาน), Credit (สินเชื่อ/การเงิน), หรือ Social Issues, Elections, Politics หรือไม่ (ตามที่เรียนใน Part 020 Step 197) — ถ้าติ๊กใช่ ระบบจะ**บล็อกไม่ให้ตั้งค่า Age, Gender, Zip Code แบบละเอียด และ Detailed Targeting บางประเภท** อัตโนมัติ เพื่อป้องกันการเลือกปฏิบัติ (Discrimination) ตามกฎหมายสหรัฐฯ ที่ Meta นำมาบังคับใช้ทั่วโลก

สำหรับแคมเปญ Awareness ทั่วไปของร้านกาแฟ/สินค้าอุปโภคบริโภค ไม่ต้องติ๊ก Checkbox นี้ แต่ถ้าคุณทำแอดให้ธุรกิจอสังหาริมทรัพย์ ธนาคาร สินเชื่อ หรือประกาศรับสมัครงาน **ต้องติ๊กเสมอ** ไม่ว่า Objective จะเป็นอะไรก็ตาม การไม่ติ๊กทั้งที่เข้าเงื่อนไขอาจทำให้โฆษณาถูก Reject หรือบัญชีถูกจำกัดสิทธิ์

### เจาะลึกเพิ่ม: กลยุทธ์การเลือก Detailed Targeting แบบ Layer (แบบมือใหม่ปลอดภัย)

สำหรับแคมเปญ Awareness แรกๆ แนะนำกลยุทธ์ "1 Layer พอ" คือเลือก Interest/Behavior หลักแค่ 3–6 คำในช่องเดียว (เงื่อนไข OR ระหว่างกัน) ไม่ต้องกด Narrow Audience ซ้อนหลายชั้น เพราะยิ่งซ้อนเงื่อนไข AND มาก Audience จะเล็กลงแบบทวีคูณ ตัวอย่างที่ปลอดภัย:

```
Detailed Targeting: Coffee, Coffeehouses, Specialty coffee, Third wave coffee
(ไม่ Narrow เพิ่ม ปล่อยเป็น OR ทั้งหมด)
```

เมื่อได้ข้อมูลจากแคมเปญนี้แล้ว ค่อยนำไปวิเคราะห์ Breakdown เพื่อหาว่า Interest ไหน Perform ดีที่สุด แล้วค่อยไปทำ Ad Set เฉพาะของ Interest นั้นในรอบถัดไป (นี่คือหลักการพื้นฐานของ Creative/Audience Testing ที่จะเจาะลึกใน Part 043–044 และ Part 046)

## Step 205: ตั้งค่า Ad Set — Placement, Budget & Schedule สำหรับแคมเปญแรก

### Placements

เลื่อนลงมาจะเจอส่วน **"Placements"** มี 2 ตัวเลือกหลัก:

- **Advantage+ placements** (เดิมชื่อ Automatic Placements) — ให้ระบบเลือกตำแหน่งแสดงโฆษณาที่ดีที่สุดให้เองอัตโนมัติ ทั่วทุก Placement ที่มี (Feed, Reels, Stories, Audience Network, Messenger) ตาม Budget ที่ตั้งไว้ Meta แนะนำตัวเลือกนี้เป็นค่า Default เพราะ Machine Learning จะกระจายงบไปยังที่ที่ให้ผลลัพธ์ดีที่สุด
- **Manual placements** — เลือกเองว่าจะให้แสดงที่ไหนบ้าง (ติ๊กถูก/ไม่ติ๊ก แต่ละ Placement) เหมาะกับกรณีที่มี Creative เฉพาะสำหรับ Placement นั้นๆ หรือต้องการตัด Placement ที่ Performance ไม่ดีออก (เช่น ตัด Audience Network ออกเพราะเจอ Traffic คุณภาพต่ำบ่อย)

สำหรับแคมเปญแรก แนะนำเลือก **Advantage+ placements (Automatic)** ไปก่อน เพื่อให้ระบบเก็บข้อมูลกว้างๆ แล้วค่อยมาดู Breakdown by Placement ใน Part 019/056 เพื่อตัดสินใจว่าควรปรับเป็น Manual ในแคมเปญถัดไปหรือไม่

### Budget & Schedule

ถ้าปิด Advantage+ Campaign Budget ไว้ที่ระดับ Campaign (ตามที่แนะนำใน Step 202) การตั้ง Budget จะมาอยู่ที่ระดับ Ad Set นี้:

- **Daily Budget** — งบต่อวัน ระบบจะพยายามใช้งบให้ใกล้เคียงจำนวนนี้ทุกวัน (อาจเกิน/ขาดได้บางวันไม่เกิน 25% ตามกลไก Pacing ของ Meta) เหมาะกับแคมเปญที่รันต่อเนื่องไม่มีกำหนดวันจบ
- **Lifetime Budget** — งบรวมทั้งแคมเปญตลอดช่วงเวลาที่กำหนด ต้องระบุ **Start Date** และ **End Date** คู่กันเสมอ เหมาะกับ Event หรือโปรโมชั่นที่มีวันจบชัดเจน ระบบจะกระจายงบให้เหมาะสมตลอดช่วงเวลานั้นเอง

สำหรับมือใหม่ แนะนำเริ่มด้วย **Daily Budget** เพราะปรับ/หยุดง่ายกว่า ควบคุมได้วันต่อวัน

**Budget เริ่มต้นที่แนะนำสำหรับ Awareness:** อย่างน้อย 100–300 บาท/วัน สำหรับตลาดไทย เพื่อให้ระบบมีงบพอที่จะหมุนหา Audience และเก็บข้อมูลได้ในระยะเวลาที่เหมาะสม (ถ้าต่ำกว่านี้มาก เช่น 20–30 บาท/วัน จะได้ Reach น้อยมากจนวัดผลไม่ได้)

### Ad Scheduling

ถ้าเลือก Lifetime Budget จะมีตัวเลือกเพิ่มคือ **"Run ads on a schedule"** — กำหนดวันและช่วงเวลาของวันที่ต้องการให้โฆษณาวิ่ง (Dayparting) เช่น วิ่งเฉพาะ จ.–ศ. เวลา 10:00–22:00 เหมาะกับธุรกิจที่รู้ชัดว่าลูกค้า Active ช่วงไหน (จะเรียนเจาะลึกเรื่อง Dayparting ใน Part 018 Step 179)

### Start & End Date

ไม่ว่าจะใช้ Budget แบบไหน ให้เช็ค **Start Date/Time** เสมอว่าตรงกับแผนที่วางไว้ (Default มักตั้งเป็น "ทันทีที่ Publish") ถ้าต้องการให้เริ่มพรุ่งนี้เช้า ต้องตั้งวันเวลาให้ตรงตั้งแต่ตอนนี้ ไม่ใช่ Publish วันนี้แล้วมาปิดพรุ่งนี้เช้า (จะเสียงบไปฟรีๆ ช่วงที่ไม่ได้ตั้งใจให้วิ่ง)

### ข้อผิดพลาดที่พบบ่อย

- ตั้ง Lifetime Budget แต่ลืมกำหนด End Date ทำให้ระบบไม่ยอมให้ Publish (ต้องมี Start-End คู่กันเสมอสำหรับ Lifetime)
- ตั้ง Daily Budget ต่ำเกินไปจนระบบ "Learning" ช้ามาก (ยิ่งงบต่ำ ยิ่งใช้เวลานานในการผ่าน Learning Phase)
- เลือก Manual Placement แล้วดันไปเลือกเฉพาะ Placement เดียว (เช่น Feed อย่างเดียว) ทำให้ Audience ที่เข้าถึงได้แคบลงมาก และ CPM สูงขึ้นเพราะแข่งประมูลในพื้นที่จำกัด

### เจาะลึกเพิ่ม: ตาราง Budget ขั้นต่ำที่แนะนำตาม Objective (สำหรับตลาดไทย)

| Objective | Daily Budget ขั้นต่ำที่แนะนำ | เหตุผล |
|---|---|---|
| Awareness (Reach) | 100–150 บาท | ต้นทุนต่อ Reach ค่อนข้างต่ำ ใช้งบน้อยได้ผลลัพธ์พอวัดได้ |
| Awareness (Brand Awareness) | 200–300 บาท | Model ต้องการ Impression มากกว่าจึงทำนายแม่นขึ้น |
| Traffic | 150–250 บาท | ต้องได้คลิกมากพอต่อวันเพื่อผ่าน Learning Phase |
| Engagement/Video Views | 100–200 บาท | ต้นทุนต่อผลลัพธ์ต่ำ แต่ต้องมี Volume พอสมควร |
| Leads | 300–500 บาท | ต้องได้ Lead อย่างน้อย ~15–25 ครั้ง/สัปดาห์เพื่อผ่าน Learning |
| Conversion (Purchase) | 500–1,000 บาท | Optimization Goal ลึกสุดของ Funnel ต้องการ Event มากที่สุดกว่าจะ Learn ได้ |

ตัวเลขเหล่านี้เป็น **แนวทางเริ่มต้น** ไม่ใช่กฎตายตัว ขึ้นกับ CPM ของอุตสาหกรรม ณ ช่วงเวลานั้นด้วย (ช่วงเทศกาล เช่น 11.11, 12.12 CPM จะพุ่งสูงกว่าปกติเพราะการแข่งขันสูง)

### เจาะลึกเพิ่ม: ทำไมการปรับ Budget ทีละมากๆ ถึง Reset Learning Phase

Meta ถือว่าการปรับ Budget เกิน **±20% ในครั้งเดียว** เป็นการเปลี่ยนแปลงที่มีนัยสำคัญมากพอที่จะทำให้ระบบต้องกลับไปเรียนรู้ Auction ใหม่บางส่วน (ไม่ Reset เต็ม 100% เหมือนเปลี่ยน Audience แต่ก็กระทบ Pacing และ Performance ชั่วคราว 1–2 วัน) หลักปฏิบัติที่แนะนำคือ ถ้าต้องการเพิ่ม Budget มาก ให้ **ปรับทีละ 15–20% ทุก 2–3 วัน** แทนการกระโดดจาก 200 บาท ไป 1,000 บาทในทีเดียว (เทคนิคนี้จะเจาะลึกอีกครั้งในเรื่อง Scaling Strategy ที่ Part 058)

## Step 206: ตั้งค่า Ad Level — เลือก Page/Instagram Account และรูปแบบ Creative (Format)

เลื่อนมาถึงระดับ **Ad** (ระดับล่างสุด) ส่วนแรกที่ต้องตั้งคือ **Identity**

### Identity (ตัวตนที่ใช้โฆษณา)

- **Facebook Page** — Dropdown เลือก Page ที่จะใช้เป็นเจ้าของโฆษณา (ชื่อ, รูปโปรไฟล์, Link ที่คนคลิกไปดู จะเป็นของ Page นี้) ถ้า Business Manager มีหลาย Page ต้องเลือกให้ถูกอันเสมอ
- **Instagram Account** — ถ้าผูก IG Account กับ Page ไว้แล้ว (ผ่าน Business Manager ตามที่เรียนใน Part 011) จะมีตัวเลือกให้ใช้ IG Account นั้นแสดงโฆษณาบน Instagram ด้วย ถ้าไม่ได้ผูกไว้ ระบบจะขึ้นข้อความ **"Use Facebook Page"** หมายความว่าโฆษณาที่ไปแสดงบน Instagram จะใช้ชื่อ/รูป Facebook Page แทน (ดู "ไม่เป็นธรรมชาติ" สำหรับผู้ใช้ IG ควรผูก IG Account จริงไว้ตั้งแต่ต้น)

### Ad Setup — Format

เลื่อนลงมาส่วน **"Ad setup"** จะให้เลือก Format ของโฆษณา:

- **Single image or video** — โฆษณา 1 ชิ้น (รูปเดียวหรือวิดีโอเดียว) เหมาะกับแคมเปญแรกที่สุด เพราะง่ายและโฟกัสข้อความเดียว
- **Carousel** — โฆษณาหลายการ์ดเลื่อนดูได้ (2–10 การ์ด) เหมาะกับการโชว์สินค้าหลายตัวหรือเล่าเรื่องเป็นขั้นตอน
- **Collection** — โฆษณาแบบ Instant Experience ที่รวมวิดีโอ/รูปหลักกับ Grid สินค้าย่อยด้านล่าง เหมาะกับ E-commerce ที่มี Catalog (จะเรียนเจาะลึกใน Part 027)

สำหรับแคมเปญ Awareness แรก แนะนำเริ่มด้วย **Single image or video** เพื่อโฟกัสการวัดผลให้ชัดเจนไม่ปนกัน

### เลือก Media

กดปุ่ม **"Add Media"** จะมีตัวเลือก:
- **Upload** — อัปโหลดไฟล์จากคอมพิวเตอร์/มือถือ
- **Select from Ads Manager library** — เลือกจากสื่อที่เคยอัปโหลดไว้ก่อนหน้า
- **Create Video** / **Use Templates** — เครื่องมือช่วยสร้างสื่ออัตโนมัติของ Meta เอง

Meta จะแนะนำให้อัปโหลดสื่อในหลาย Ratio พร้อมกัน (1:1 Square, 4:5 Vertical, 9:16 Full Vertical สำหรับ Stories/Reels) เพื่อให้ระบบเลือกไฟล์ที่เหมาะกับแต่ละ Placement โดยอัตโนมัติ — ถ้าอัปโหลดแค่ไฟล์ 16:9 แนวนอนไฟล์เดียว โฆษณาบน Reels/Stories จะถูก Crop กลางภาพซึ่งอาจดูแย่หรือตัดข้อความสำคัญออก

### ข้อผิดพลาดที่พบบ่อย

- เลือก Page ผิด (มีหลาย Page ในบัญชี แล้วสลับกันจำสับสน)
- อัปโหลดไฟล์ Ratio เดียว (16:9) ทั้งที่เปิด Automatic Placement ครอบคลุมทุกตำแหน่ง ทำให้ภาพเพี้ยนบน Story/Reels
- ไม่ผูก Instagram Account ทำให้โฆษณาบน IG ดูไม่น่าเชื่อถือ (ใช้ชื่อ Facebook Page แทน)

### เจาะลึกเพิ่ม: ขนาดไฟล์และ Spec มาตรฐานที่ควรจำ

| Ratio | ใช้กับ Placement | ขนาดแนะนำ (พิกเซล) | หมายเหตุ |
|---|---|---|---|
| 1:1 (Square) | Feed | 1080 x 1080 | ใช้งานได้กว้างที่สุด |
| 4:5 (Vertical) | Feed มือถือ | 1080 x 1350 | กินพื้นที่จอมือถือมากกว่า 1:1 |
| 9:16 (Full Vertical) | Stories, Reels | 1080 x 1920 | ห้ามมีข้อความ/โลโก้ในขอบบน-ล่าง 14% (โดน UI ของแพลตฟอร์มบัง) |

ไฟล์วิดีโอ: แนะนำ MP4 (H.264), ขนาดไม่เกิน 4GB, ความยาวสำหรับ Awareness ควรอยู่ที่ 15–30 วินาที (สั้นกว่า Conversion Ads เพราะเป้าหมายคือให้จดจำ ไม่ใช่โน้มน้าวซื้อ)

### เจาะลึกเพิ่ม: Dynamic Creative — ทางเลือกสำหรับมือใหม่ที่ยังไม่มั่นใจว่า Creative ไหนดีที่สุด

ใต้ส่วน Ad Setup จะมี Toggle **"Dynamic Creative"** ถ้าเปิดใช้ ระบบจะให้คุณอัปโหลด Media หลายตัว + เขียน Primary Text หลายเวอร์ชัน + Headline หลายเวอร์ชัน จากนั้นระบบจะ**สลับผสมกันอัตโนมัติ**และเรียนรู้ว่าชุดไหน Perform ดีที่สุด เหมาะกับตอนที่ยังไม่มั่นใจว่า Copy/ภาพไหนดีที่สุด แต่ข้อจำกัดคือ**ดู Insight แยกเป็นราย Combination ไม่ได้ละเอียดเท่า A/B Test แบบ Manual** (จะเจาะลึกเปรียบเทียบ Dynamic Creative กับ A/B Testing แบบ Manual ใน Part 043)

## Step 207: เขียน Ad Copy และอัปโหลดสื่อสำหรับแคมเปญแรก

### ส่วนของ Ad Copy

ในหน้า Ad เลื่อนต่อจาก Media จะเจอ:

- **Primary Text** (ข้อความหลัก) — สูงสุด 125 ตัวอักษรที่แสดงเต็มก่อนถูกตัดเป็น "See more" ควรใส่ Hook สำคัญในบรรทัดแรกสุด เพราะบนมือถือ Facebook จะตัดข้อความสั้นกว่านี้อีก (ประมาณ 3 บรรทัดแรกที่เห็นก่อน tap "See more")
- **Headline** (พาดหัว) — สูงสุด 40 ตัวอักษร แสดงตัวหนาใต้ภาพ/วิดีโอ (แสดงเฉพาะบาง Placement เช่น Feed, ไม่แสดงบน Stories/Reels เต็มรูปแบบ)
- **Description** (คำอธิบายเสริม) — สูงสุด 30 ตัวอักษร แสดงใต้ Headline อีกชั้น (แสดงเฉพาะบาง Placement เช่นกัน)

สำหรับแคมเปญ Awareness สิ่งที่ Primary Text ควรทำคือ **สร้างการจดจำ** ไม่ใช่ Hard Sell — เน้นเล่าเรื่องแบรนด์ ปัญหาที่แบรนด์แก้ให้ลูกค้า หรือข่าวที่น่าสนใจ (เปิดสาขาใหม่, ครบรอบกี่ปี) มากกว่าพูดถึงราคา/โปรโมชั่นแบบ Traffic/Sales Campaign

### Destination

ส่วน **"Destination"** — สำหรับ Awareness แคมเปญที่ไม่ได้เน้นให้คนคลิกไปไหน อาจไม่มี Field นี้ชัดเจนเท่า Objective อื่น แต่ถ้าเลือกใส่ Website URL ไว้ ให้ใส่ในช่อง **"Website URL"** พร้อมตั้งค่า UTM ผ่านช่อง **"URL Parameters"** ใน "Ad setup" > แถบ "Advanced" (ปุ่มขยาย "Show more options")

### Call to Action (CTA)

Dropdown เลือกปุ่มกดที่จะแสดงบนโฆษณา เช่น "Learn More", "Send Message", "Get Directions" (เหมาะกับหน้าร้าน), "Contact Us" — สำหรับ Awareness ถ้าไม่มี Landing Page ชัดเจน อาจเลือก "Learn More" หรือ "Send Message" เพื่อเปิดการสนทนากับลูกค้าที่สนใจ

### Preview โฆษณา

ด้านขวาของหน้าจอ Ads Manager จะมี **Ad Preview Panel** แสดงตัวอย่างโฆษณาตาม Placement ต่างๆ (Feed, Story, Reels, Marketplace ฯลฯ) มี Dropdown ให้สลับดูแต่ละ Placement — **ต้องเช็คทุก Placement ก่อน Publish เสมอ** เพราะบางครั้งข้อความยาวเกินไปจนถูกตัดในบาง Format หรือรูปถูก Crop จนดูแปลก

### ข้อผิดพลาดที่พบบ่อย

- เขียน Primary Text ยาวเป็นพารากราฟใหญ่โดยไม่มี Hook ในบรรทัดแรก ทำให้คนเลื่อนผ่านก่อนจะอ่านถึงเนื้อหาสำคัญ
- Hard Sell ราคา/โปรโมชั่นในแคมเปญ Awareness (ควรเก็บไว้ใช้กับ Traffic/Conversion Campaign แทน)
- ไม่เช็ค Preview บน Story/Reels ทำให้ข้อความ Overlay ทับกับปุ่ม UI ของแพลตฟอร์ม

### เจาะลึกเพิ่ม: โครงสร้าง Primary Text ที่ใช้ได้ผลกับ Awareness Campaign

ลองใช้โครงสร้าง 3 ส่วนนี้เป็นแนวทาง:

1. **บรรทัดแรก (Hook)** — ประโยคสั้น กระตุ้นความสนใจ หรือถามคำถามที่กลุ่มเป้าหมายอยากรู้คำตอบ เช่น "รู้ไหมว่าลาดพร้าวมีร้านกาแฟที่คั่วเมล็ดเองทุกวัน?"
2. **บรรทัดกลาง (เนื้อเรื่อง)** — เล่าเรื่องแบรนด์สั้นๆ 1–2 ประโยค ให้ความรู้สึกเป็นมนุษย์ ไม่ใช่ประกาศขาย
3. **บรรทัดปิด (Soft CTA)** — ชวนให้ทำอะไรต่อแบบไม่กดดัน เช่น "แวะมาชิมได้ตั้งแต่วันที่ 1 ต.ค. นี้ 📍"

ตัวอย่างเต็ม:
```
รู้ไหมว่าลาดพร้าวมีร้านกาแฟที่คั่วเมล็ดเองทุกวัน? ☕

Bean & Brew สาขา 2 เปิดแล้วที่ซอยลาดพร้าว 71 
คั่วสดใหม่ทุกเช้า ชงด้วยบาริสต้าที่ผ่านการแข่งขันระดับประเทศ

แวะมาชิมแก้วแรกได้ตั้งแต่วันที่ 1 ต.ค. นี้ 📍
```

### เจาะลึกเพิ่ม: การใช้ Emoji และสัญลักษณ์ใน Ad Copy

Emoji ช่วยดึงความสนใจในฟีดที่มีข้อความเยอะ แต่ควรใช้แบบ "จุดเน้น" ไม่ใช่ "แทนคำ" ทุกคำ — ใช้ 2–4 ตัวต่อโพสต์ก็เพียงพอ วางไว้ต้นบรรทัดหรือปิดท้ายประโยคสำคัญ หลีกเลี่ยงการใช้ Emoji ที่ Meta อาจตีความว่าเป็น "Sensational" เกินจริง (เช่น 🔥🔥🔥 ซ้ำๆ, ลูกศรกระพริบชี้ปุ่ม CTA) เพราะอาจกระทบ Ad Relevance/Quality Ranking

## Step 208: หน้า Review ก่อน Publish — เช็กอะไรบ้างก่อนกดปุ่มสีเขียว

ก่อนกดปุ่ม **"Publish"** สีเขียวมุมขวาบน ให้ไล่เช็ก 8 จุดนี้ทุกครั้ง:

1. **Ad Account ถูกต้อง** — เช็คมุมบนซ้ายอีกครั้ง (ย้ำเพราะสำคัญที่สุด)
2. **Campaign Objective** ตรงกับที่ตั้งใจ (Awareness / Reach หรือ Brand Awareness)
3. **Campaign Name** ตามสูตร Naming Convention
4. **Ad Set: Location** ตรงพื้นที่เป้าหมาย ไม่มีพื้นที่หลุดเข้ามาโดยไม่ตั้งใจ
5. **Ad Set: Age/Gender/Detailed Targeting** สมเหตุสมผลกับสินค้า
6. **Ad Set: Budget & Schedule** — ตัวเลขงบถูกต้อง, วันเริ่ม-จบถูกต้อง (เผลอพิมพ์เลขเกินบ่อยมาก เช่น ตั้งใจ 300 บาท/วัน แต่พิมพ์ 3000 บาท/วัน)
7. **Ad: Page/IG ถูกต้อง, Media ครบ Ratio, Copy ไม่มีคำผิด, ลิงก์ Destination ใช้งานได้จริง (คลิกลิงก์ทดสอบก่อน Publish)**
8. **Ad Preview** ครบทุก Placement ที่เปิดใช้

### Errors และ Warnings ที่ระบบแจ้งก่อน Publish

Ads Manager จะมีแถบ **"Errors"** และ **"Warnings"** ปรากฏถ้าตั้งค่าไม่สมบูรณ์ (เช่น ลืมใส่ Media, ข้อความเกินตัวอักษรที่กำหนด, Detailed Targeting ขัดกับ Special Ad Category) ต้องแก้ Errors ทั้งหมดก่อนจึงจะกด Publish ได้ ส่วน Warnings เป็นคำเตือนที่ยัง Publish ได้แต่ควรอ่านให้เข้าใจก่อน (เช่น เตือนว่า Audience แคบเกินไป)

### กดปุ่ม Publish

หลังเช็กครบ ให้กดปุ่ม **"Publish"** ระบบจะส่งโฆษณาเข้าสู่ขั้นตอน **Ad Review** (ตรวจสอบตาม Advertising Policies ที่เรียนใน Part 007 และ Part 020) สถานะจะเปลี่ยนเป็น **"In review"** โดยทั่วไปใช้เวลาไม่กี่นาทีถึง 24 ชั่วโมง

### ข้อผิดพลาดที่พบบ่อย

- กด Publish รีบเกินไปโดยไม่เช็ค Preview ทำให้พบ Error หลังโฆษณาเริ่มวิ่งไปแล้วครึ่งวัน (เสียเวลาและงบ)
- เจอ Warning แล้วเผลอมองข้ามโดยไม่อ่าน ทำให้พลาดจุดสำคัญ เช่น Audience แคบเกินไปจนทำนายว่าจะได้ Reach ต่ำ
- ไม่ทดสอบคลิกลิงก์ Destination ก่อน Publish ทำให้ลิงก์พังหรือพาไปหน้าที่ผิด

### เจาะลึกเพิ่ม: ความแตกต่างระหว่าง Error, Warning และ Policy Rejection

มือใหม่มักสับสน 3 คำนี้ ทั้งที่มีความหมายและวิธีจัดการต่างกันโดยสิ้นเชิง:

| ประเภท | เกิดตอนไหน | ตัวอย่าง | ต้องทำอะไร |
|---|---|---|---|
| **Error** | ตอนพยายาม Publish | ลืมใส่ Media, ไม่มี End Date สำหรับ Lifetime Budget | ต้องแก้ให้หมดก่อน ระบบไม่ยอมให้ Publish |
| **Warning** | ตอนพยายาม Publish | Audience แคบเกินไป, Placement บางอันไม่รองรับ Format ที่เลือก | Publish ได้แต่ควรอ่านและพิจารณาก่อน |
| **Policy Rejection** | หลัง Publish ระหว่างขั้น Ad Review | เนื้อหาละเมิด Advertising Policies (เช่น Personal Attributes, Overclaim) | ต้อง Appeal หรือแก้ Creative แล้วส่งใหม่ (ตามที่เรียนใน Part 020 Step 195) |

การแยกแยะ 3 อย่างนี้ให้ถูกจะช่วยให้คุณไม่ตื่นตระหนกเกินเหตุเมื่อเห็นข้อความเตือนสีเหลือง/แดงบนหน้าจอ

### เจาะลึกเพิ่ม: หน้า Review แบบละเอียด — สิ่งที่ Ads Manager แสดงให้เห็นก่อนกด Publish

หน้า Review (บางเวอร์ชัน UI เรียก "Review and Publish") จะสรุปโครงสร้างทั้ง 3 ระดับเป็น Nested List ให้เลื่อนดูทีละชั้น พร้อมปุ่ม **"Edit"** ข้างแต่ละบล็อกให้กระโดดกลับไปแก้ได้ทันทีโดยไม่ต้องกด Back ทั้งหน้า ใช้ปุ่มนี้แทนการกด Browser Back เสมอ เพราะการกด Back ของเบราว์เซอร์บางครั้งทำให้ข้อมูลที่กรอกไว้หายหมด

## Step 209: หลัง Publish — สิ่งที่ต้องเช็กใน 24–48 ชั่วโมงแรก และข้อผิดพลาดที่พบบ่อยของมือใหม่

### สถานะที่ต้องติดตาม

หลัง Publish สถานะ Campaign/Ad Set/Ad จะไล่เปลี่ยนตามลำดับ: **In review → Active** (ถ้าผ่านการตรวจสอบ) หรือ **Rejected/Disapproved** (ถ้าไม่ผ่าน) ให้เช็คสถานะทุก 2–3 ชั่วโมงในวันแรก

### เช็คลิสต์ 24 ชั่วโมงแรก

1. **สถานะ Active หรือไม่** — ถ้ายัง "In review" นานเกิน 24 ชั่วโมง ให้ตรวจสอบว่า Payment Method มีปัญหาหรือไม่ (เช็คแถบแจ้งเตือนสีแดงบนสุดของ Ads Manager)
2. **Delivery Insights** — คลิกเข้าไปที่ Ad Set จะเห็นข้อความสถานะ Delivery เช่น "Active", "Learning", "Limited" ให้อ่านทำความเข้าใจ
3. **Impressions เริ่มขึ้นหรือยัง** — ถ้า Active มาแล้ว 3–4 ชั่วโมงแต่ Impressions = 0 ให้เช็ค Audience ว่าแคบเกินไปหรือ Budget ตั้งต่ำเกินไปหรือไม่
4. **Amount Spent เทียบกับ Daily Budget** — เช็คว่าระบบใช้งบตามที่ตั้งไว้หรือไม่ (Pacing ปกติ)
5. **CPM เทียบกับ Benchmark** — สำหรับตลาดไทย CPM ของ Awareness มักอยู่ที่ประมาณ 30–100+ บาท ต่อ 1,000 Impressions ขึ้นกับกลุ่มเป้าหมายและ Placement (ตัวเลขนี้ผันผวนตามฤดูกาลและการแข่งขัน ให้ใช้เป็น Reference กว้างๆ)
6. **Frequency** — ถ้าเลือก Objective Reach และตั้ง Frequency Cap ไว้ ให้เช็คว่าไม่เกินค่าที่ตั้ง
7. **Ad Relevance Diagnostics** (Quality Ranking, Engagement Rate Ranking, Conversion Rate Ranking) — เริ่มปรากฏหลังมี Impressions ระดับหนึ่ง เอาไว้ดูว่าโฆษณาคุณเทียบกับคู่แข่งที่แย่งกลุ่มเป้าหมายเดียวกันเป็นอย่างไร
8. **คอมเมนต์ใต้โพสต์โฆษณา** — เข้าไปดูว่ามีคำถาม/คำติชมจากลูกค้าไหม ควรตอบให้เร็ว (ภายในไม่กี่ชั่วโมง) เพราะ Response Time มีผลต่อความน่าเชื่อถือของ Page

### ข้อผิดพลาดที่พบบ่อยที่สุดของมือใหม่ในช่วงนี้

1. **ปิดแคมเปญเร็วเกินไป** — เห็นผลลัพธ์ยังไม่ดีใน 2–3 ชั่วโมงแรกแล้วรีบปิด ทั้งที่ระบบยังอยู่ใน Learning Phase (ตามที่เรียนใน Part 009 Step 86) ควรให้เวลาอย่างน้อย 24–48 ชั่วโมง หรือจนกว่าจะได้ผลลัพธ์ (Result) อย่างน้อย 15–25 ครั้งตาม Optimization Goal ก่อนตัดสินใจ
2. **แก้ไข Ad Set บ่อยเกินไป** — ปรับ Budget, Audience, Creative ทุก 2–3 ชั่วโมง ทำให้ Learning Phase Reset ใหม่ทุกครั้ง (การแก้ไขที่มีผล Reset Learning เช่น เปลี่ยน Audience, เปลี่ยน Optimization Goal, ปรับ Budget เกิน 20% ในทีเดียว)
3. **ตกใจกับ CPM สูงในชั่วโมงแรก** — ช่วงเริ่มต้น Machine Learning ยังไม่เจอ Audience ที่ดีที่สุด ตัวเลขจะแพงกว่าปกติ แล้วค่อยๆ ดีขึ้นเมื่อระบบเรียนรู้
4. **ไม่เช็คเงินในบัญชี** — ลืมเช็คว่าบัตร/Payment Method ยังใช้งานได้ ทำให้แคมเปญหยุดกลางทางโดยไม่รู้ตัว
5. **สับสนระหว่าง Reach และ Impressions** — เข้าใจผิดคิดว่าตัวเลขเดียวกัน ทั้งที่ Reach คือคนไม่ซ้ำ ส่วน Impressions คือจำนวนครั้งที่แสดงทั้งหมด (คนเดียวอาจเห็นหลายครั้ง)
6. **ไม่บันทึกผลลัพธ์เป็น Baseline** — ลืมจดตัวเลขวันแรกๆ ไว้เทียบกับแคมเปญถัดไป ทำให้ไม่มีข้อมูลเปรียบเทียบว่าดีขึ้นหรือแย่ลง

### ข้อผิดพลาดที่พบบ่อย (สรุปเพิ่มเติม)

- ปิด Ad Set ที่ยังอยู่ Learning Phase เพราะใจร้อน
- ไม่ตอบคอมเมนต์ลูกค้าใต้โพสต์โฆษณา ทำให้ดูไม่น่าเชื่อถือ
- ไม่บันทึก Baseline Metrics ไว้เทียบแคมเปญถัดไป

### เจาะลึกเพิ่ม: ตาราง Diagnosis เมื่อผลลัพธ์ไม่เป็นไปตามคาดใน 48 ชั่วโมงแรก

| อาการที่เห็น | สาเหตุที่เป็นไปได้ | วิธีตรวจสอบ/แก้ไข |
|---|---|---|
| สถานะค้างที่ "In review" นานเกิน 24 ชม. | Payment Method มีปัญหา หรือ Page ใหม่เกินไปยังไม่ผ่านการตรวจสอบพื้นฐาน | เช็คแถบแจ้งเตือนสีแดงบนสุด, เช็ค Billing ใน Business Settings |
| Impressions = 0 หลัง Active มา 4+ ชม. | Audience แคบเกินไป หรือ Budget ต่ำเกินกว่าจะแข่งประมูลได้ | เช็ค Audience Size, ลองเพิ่ม Budget ชั่วคราวหรือขยาย Audience |
| CPM สูงกว่า Benchmark มากในวันแรก | ปกติของ Learning Phase ต้นๆ, หรือ Audience แข่งขันสูง (ช่วงเทศกาล) | รอดูอีก 1–2 วัน ถ้ายังสูงผิดปกติให้เช็คการแข่งขันในหมวดธุรกิจนั้น |
| Frequency พุ่งเร็วผิดปกติ | Audience เล็กเกินไปเทียบกับ Budget | ขยาย Location/Detailed Targeting หรือลด Budget ลง |
| Delivery Insight แจ้ง "Learning Limited" | Budget ต่ำเกินไปเทียบกับ Optimization Goal หรือ Audience แคบมาก | เพิ่ม Budget แบบค่อยเป็นค่อยไป (ไม่เกิน 20% ต่อครั้ง) |
| Ad ถูก Reject หลัง Active ไปแล้วบางชั่วโมง | Meta สุ่มตรวจซ้ำ (Re-review) แล้วพบปัญหา Policy | เช็คอีเมล/Notification เรื่อง Policy จาก Meta, อ่านเหตุผลที่แจ้งแล้ว Appeal ตามขั้นตอน Part 020 |

### เจาะลึกเพิ่ม: การตั้ง Routine เช็คแคมเปญประจำวัน (Daily Check Routine)

แนะนำให้สร้างนิสัยเช็คแคมเปญตามช่วงเวลานี้ทุกวัน (โดยเฉพาะ 7 วันแรกของแคมเปญใหม่):
- **เช้า (ก่อนเริ่มงาน)** — เช็คสถานะรวมทุกแคมเปญ ว่ามีอันไหน Active/Learning/Limited/Rejected
- **กลางวัน** — เช็ค Amount Spent เทียบ Budget ว่า Pacing ปกติหรือไม่
- **เย็น (ก่อนเลิกงาน)** — สรุปตัวเลขของวัน บันทึกลง Tracker (ตามที่เรียนใน Part 004 Step 38) เพื่อเห็น Trend รายวัน

การเช็คเป็น Routine แบบนี้ (ไม่ใช่เปิดดูตลอดเวลาแบบวิตกกังวล) จะช่วยให้คุณจับปัญหาได้เร็วโดยไม่ต้อง "เฝ้าหน้าจอ" ทั้งวันซึ่งเป็นพฤติกรรมที่มักนำไปสู่การแก้ไขแคมเปญบ่อยเกินไปโดยไม่จำเป็น

## Case Study: ร้านกาแฟ "Bean & Brew" เปิดสาขาใหม่ที่ลาดพร้าว

**สถานการณ์:** ร้านกาแฟ Specialty เปิดสาขาที่ 2 ในซอยลาดพร้าว ต้องการให้คนในพื้นที่รู้จักร้านภายใน 2 สัปดาห์ก่อนวันเปิดจริง งบโฆษณา 3,000 บาท

**การตั้งค่าที่ทำ:**
- Objective: Awareness → Reach
- Ad Set: Location = Drop Pin รัศมี 5 กม. รอบร้าน, Age 20–45, Gender All, ไม่ใส่ Detailed Targeting เพิ่ม (ปล่อยกว้างเพราะเน้น Reach คนในพื้นที่)
- Frequency Cap: ไม่เกิน 3 ครั้ง ต่อ 7 วัน (ป้องกันคนเดิมเห็นถี่จนเบื่อ)
- Budget: Daily Budget 200 บาท/วัน เป็นเวลา 15 วัน
- Placement: Advantage+ (Automatic)
- Creative: วิดีโอ 15 วินาที เปิดฉากด้วยภาพบาริสต้าชงกาแฟ (Hook 3 วินาทีแรก) ปิดท้ายด้วยที่อยู่และวันเปิด

**ผลลัพธ์หลัง 15 วัน:**
- Reach: 42,000 คนไม่ซ้ำ ในพื้นที่รัศมี 5 กม.
- Frequency: 2.1 (อยู่ในเกณฑ์ที่ตั้งไว้)
- CPM เฉลี่ย: 45 บาท
- วันเปิดร้านจริง มีลูกค้าถามที่ Comment ใต้โพสต์ว่า "เห็นในไอจีตลอดเลย วันนี้มาแล้วค่ะ" มากกว่า 30 คอมเมนต์ และหน้าร้านมีคนเข้าคิวตั้งแต่เช้าวันเปิด

**สิ่งที่เรียนรู้:** แคมเปญ Awareness ที่ Setup ถูกต้องตามหลักการ (Location เจาะจงตามรัศมีจริง, Frequency Cap ป้องกันความเบื่อ, Creative มี Hook ชัด) สามารถสร้างผลลัพธ์ทางธุรกิจจริงได้ แม้จะเป็น Objective ที่ไม่ได้วัด "ยอดขาย" ตรงๆ — ตัวชี้วัดความสำเร็จของแคมเปญนี้ไม่ใช่ ROAS แต่คือ "คนจดจำและมาเปิดร้านวันแรก" ซึ่งวัดได้จาก Comment/Engagement และจำนวนลูกค้าหน้าร้านจริง

## Case Study 2: คอร์สออนไลน์ "สอนภาษาอังกฤษเพื่อธุรกิจ" ทดสอบ Brand Awareness ก่อนเปิดตัว

**สถานการณ์:** ผู้สอนภาษาอังกฤษออนไลน์เตรียมเปิดคอร์สใหม่ในอีก 3 สัปดาห์ ยังไม่มีสินค้าให้ขายจริง (คอร์สยังไม่เปิดจอง) ต้องการให้กลุ่มเป้าหมายรู้จักชื่อผู้สอนและเพจก่อน เพื่อให้เมื่อเปิดขายจริงจะมีคนจำได้และกดสนใจง่ายขึ้น งบทดลอง 5,000 บาท ใน 10 วัน

**การตั้งค่าที่ทำ:**
- Objective: Awareness → Brand Awareness (เพราะมีงบพอสมควรและต้องการวัด Ad Recall จริงจัง ไม่ใช่แค่ Reach)
- Ad Set: ไม่ใช้ Location แบบ Radius (เพราะเป็นออนไลน์คอร์ส) ตั้ง Location = ประเทศไทยทั้งประเทศ, Age 24–45, Detailed Targeting = "English language", "Business English", "Toastmasters International" (Interest ที่เกี่ยวกับการพัฒนาตนเองด้านภาษา)
- Budget: Daily Budget 500 บาท/วัน x 10 วัน
- Creative: วิดีโอ 20 วินาที ผู้สอนพูดตรงกล้อง เล่าปัญหาที่คนเรียนภาษาอังกฤษเพื่อธุรกิจเจอบ่อย (Hook: "คุณเคยพรีเซนต์งานเป็นภาษาอังกฤษแล้วสมองว่างไปกลางประโยคไหม?")

**ผลลัพธ์หลัง 10 วัน:**
- Estimated Ad Recall Lift: ระบบรายงาน "Estimated 890 People" ที่มีโอกาสจดจำโฆษณาได้เพิ่มขึ้น จากงบที่ใช้ไป 5,000 บาท
- Cost per Estimated Ad Recall Lift: ประมาณ 5.6 บาทต่อคน
- Page Follower เพิ่มขึ้น 210 คนโดยไม่ได้ตั้งใจ (ผลพลอยได้จากการที่คนกดเข้าเพจไปดูข้อมูลเพิ่ม)
- เมื่อเปิดขายคอร์สจริงในสัปดาห์ที่ 4 (ด้วยแคมเปญ Conversion แยกอีกตัว) อัตราการปิดการขายจากคนที่เคยเห็นแคมเปญ Awareness นี้มาก่อน สูงกว่ากลุ่มที่ไม่เคยเห็นเลยอย่างชัดเจน (วัดจาก Custom Audience ที่สร้างจากคนที่ Engage กับวิดีโอ Awareness นี้)

**สิ่งที่เรียนรู้:** แคมเปญ Awareness ไม่ใช่แค่ "เผาเงินให้คนเห็น" แต่เมื่อวางแผนร่วมกับ Funnel ที่มีขั้นต่อไปรออยู่ (เปิดขายคอร์สในอีก 3 สัปดาห์) มันทำหน้าที่ **"อุ่นเครื่อง" (Warm-up)** กลุ่มเป้าหมายให้พร้อมก่อนเจอ Offer จริง ซึ่งเป็นหลักการที่เราจะเรียนเจาะลึกอีกครั้งในเรื่อง Full-Funnel Strategy ที่ Part 050

## FAQ — คำถามที่พบบ่อยเกี่ยวกับแคมเปญแรก

**Q: สร้างแคมเปญแรกแล้วควรรอกี่วันก่อนตัดสินใจว่าดีหรือไม่ดี?**
A: อย่างน้อย 3–4 วัน หรือจนกว่า Ad Set จะได้ Result ตาม Optimization Goal อย่างน้อย 15–25 ครั้ง (ตามที่ Meta ใช้เป็นเกณฑ์อ้างอิงสำหรับ Learning Phase) การตัดสินใจจากข้อมูลไม่กี่ชั่วโมงแรกมักผิดพลาดเพราะระบบยังไม่ผ่าน Learning

**Q: ถ้าตั้งค่าผิดหลัง Publish ไปแล้ว แก้ตรงไหนได้บ้าง แก้ตรงไหนไม่ได้?**
A: แก้ได้: Budget, Schedule (บางส่วน), Audience (Location/Age/Gender/Detailed Targeting), Placement, Creative (Copy/Media), CTA — แก้ไม่ได้ (ต้องสร้างใหม่): Campaign Objective, Buying Type การเปลี่ยน Objective คือการเปลี่ยนแก่นของแคมเปญ Meta จึงบังคับให้สร้างใหม่เท่านั้น

**Q: ทำไม Reach ที่ได้จริงน้อยกว่า Audience Size ที่ระบบ Estimate ไว้ตอนตั้งค่ามาก?**
A: Audience Size คือ "เพดานสูงสุด" ของกลุ่มที่เข้าเงื่อนไข ไม่ใช่การันตีว่าจะเข้าถึงได้ทั้งหมด — ขึ้นกับ Budget, ระยะเวลาที่รัน, การแข่งขันในตลาด (Auction) ด้วย งบน้อยกับ Audience ใหญ่มาก จะเข้าถึงได้เพียงเสี้ยวเดียวของ Audience Size ที่แสดง

**Q: จำเป็นไหมที่ต้องมี Landing Page สำหรับแคมเปญ Awareness?**
A: ไม่จำเป็นเสมอไป ถ้าเป้าหมายแท้จริงคือให้คนรู้จักแบรนด์ ปุ่ม CTA อาจนำไปที่ Facebook Page หรือเปิดกล่องแชท Messenger ก็ได้ ไม่ต้องมี Landing Page เฉพาะ แต่ถ้าต้องการเก็บข้อมูล Pixel เพื่อสร้าง Custom Audience ในอนาคต การมี Landing Page ง่ายๆ ให้คนคลิกไปดูจะมีประโยชน์มากกว่า

**Q: ควรยิง Awareness ควบคู่กับ Conversion Campaign พร้อมกันเลยไหม?**
A: สำหรับธุรกิจใหม่ที่ยังไม่มีข้อมูล Pixel เลย แนะนำให้เริ่มที่ Traffic หรือ Conversion Campaign งบน้อยควบคู่กันได้ทันที ไม่ต้องรอ Awareness อย่างเดียวก่อน เพราะการเก็บข้อมูล Pixel ควรเริ่มเร็วที่สุด ส่วน Awareness ใช้เป็นแคมเปญเสริมสำหรับ Brand Building ระยะยาวไปพร้อมกัน

## Checklist ท้ายบท

- [ ] เข้า Ads Manager ผ่าน Ad Account ที่ถูกต้อง เช็คมุมบนซ้ายก่อนสร้างแคมเปญทุกครั้ง
- [ ] เลือก Buying Type = Auction, Objective = Awareness, Performance Goal = Reach หรือ Brand Awareness ตามเหมาะสม
- [ ] ตั้งชื่อ Campaign/Ad Set/Ad ตาม Naming Convention มาตรฐานของตัวเอง
- [ ] ตั้ง Location, Age, Gender, Detailed Targeting ให้ตรงกลุ่มเป้าหมายจริง ไม่แคบเกินไป
- [ ] เลือก Placement = Advantage+ (Automatic) สำหรับแคมเปญแรก
- [ ] ตั้ง Daily Budget อย่างน้อย 100–300 บาท/วัน พร้อม Start/End Date ถูกต้อง

## Workshop / แบบฝึกหัด

**เป้าหมาย:** สร้างแคมเปญ Awareness จริง 1 แคมเปญในบัญชีของตัวเอง (หรือบัญชีทดสอบ) ให้ครบทุกขั้นตอนตาม Part นี้

**ขั้นตอน:**

1. เลือกธุรกิจ/สินค้าจริง 1 ตัว (ของตัวเองหรือลูกค้า) ที่ต้องการสร้าง Brand Awareness
2. เปิด Ads Manager แล้วสร้าง Campaign ใหม่ Objective = Awareness เลือก Reach เป็น Performance Goal
3. ตั้งชื่อ Campaign ตามสูตร `[วันที่]_AWR_[ชื่อธุรกิจ]_V1`
4. ตั้ง Ad Set: กำหนด Location ตามพื้นที่ธุรกิจจริง (ใช้ Drop Pin ถ้ามีหน้าร้าน), Age/Gender ตาม Persona ที่เคยทำใน Part 005, ไม่ต้องใส่ Detailed Targeting ในรอบแรก
5. ตั้ง Daily Budget 100–200 บาท (หรือใช้ตัวเลขสมมติถ้าเป็นบัญชีทดสอบ)
6. ตั้งชื่อ Ad Set ตามสูตร Naming Convention ของตัวเอง
7. สร้าง Ad: เลือก Page จริง, อัปโหลดรูป/วิดีโออย่างน้อย 2 Ratio, เขียน Primary Text ที่มี Hook ในบรรทัดแรก, เลือก CTA ที่เหมาะสม
8. เปิด Ad Preview เช็คทุก Placement แล้วถ่ายภาพหน้าจอเก็บไว้เป็นหลักฐานการทำ Workshop
9. ไล่เช็ก 8 จุดตาม Checklist หน้า Review
10. ถ้าเป็นบัญชีจริงพร้อมงบจริง ให้กด Publish แล้วบันทึกตัวเลข Baseline (Reach, CPM, Frequency) วันแรกไว้ในสมุด/Sheet ส่วนตัวเพื่อเทียบกับแคมเปญถัดไปใน Part 022

**คำถามให้ตอบหลังทำ Workshop:**
- Audience Size ที่ระบบแสดงตอนตั้งค่า อยู่ในช่วงที่เหมาะสม (500,000–2,000,000) หรือไม่ ถ้าไม่ ควรปรับอย่างไร
- Preview บน Story/Reels ภาพ/วิดีโอถูก Crop จนเสียองค์ประกอบหรือไม่
- ถ้าแคมเปญนี้เป็นแคมเปญจริง คุณตั้ง Frequency Cap ไว้หรือไม่ เพราะเหตุใด

### ส่วนขยาย Workshop (สำหรับผู้ที่มีบัญชีจริงและงบทดลอง)

ถ้าคุณมีบัญชีจริงพร้อมงบทดลองอย่างน้อย 1,000–1,500 บาท ให้ทำต่อดังนี้เพื่อฝึกการเปรียบเทียบ:

1. Duplicate Ad Set ที่สร้างไว้ (คลิกขวา → Duplicate) ให้ได้ Ad Set ที่ 2 ในแคมเปญเดียวกัน
2. ใน Ad Set ที่ 2 เปลี่ยนแค่ **Detailed Targeting** เป็นกลุ่มคำที่ต่างจากอันแรก (เช่น ถ้าอันแรกใช้ "Coffee" อันที่ 2 ใช้ "Small business owners" หรือ Interest ที่ต่างมุมมองกัน) ส่วนอื่น (Location, Age, Budget) คงเดิมทุกอย่าง
3. ปล่อยให้ทั้ง 2 Ad Set รันพร้อมกันอย่างน้อย 3–4 วัน
4. เปิดตาราง Ads Manager เทียบ CPM, Reach, Frequency ของทั้ง 2 Ad Set ว่าอันไหน Perform ดีกว่า
5. บันทึกผลเป็น Insight ส่วนตัว เก็บไว้ใช้ต่อในแคมเปญ Traffic ที่จะสร้างใน Part 022 (Audience ที่ Perform ดีใน Awareness มักเป็นจุดเริ่มต้นที่ดีสำหรับ Objective อื่นด้วย แม้ผลลัพธ์จะไม่ Transfer ตรงเป๊ะ 100% ก็ตาม)

### เกณฑ์ประเมินผล Workshop (Self-Assessment)

ให้คะแนนตัวเองข้อละ 1 คะแนน (เต็ม 10) ตามหัวข้อต่อไปนี้ ถ้าได้ต่ำกว่า 8 ให้กลับไปอ่านเนื้อหา Step ที่เกี่ยวข้องอีกครั้งก่อนไปต่อ Part 022:

1. เลือก Ad Account ถูกต้องตั้งแต่ต้น
2. เลือก Objective/Performance Goal เหมาะสมกับเป้าหมายจริงของธุรกิจ
3. ตั้งชื่อ Campaign/Ad Set/Ad ตาม Naming Convention ครบทั้ง 3 ระดับ
4. Location/Age/Gender ตรงกับ Persona ของธุรกิจ ไม่ใช้ Default แบบไม่คิด
5. Detailed Targeting ไม่แคบเกินไป (Audience Size อยู่ในช่วงที่เหมาะสม)
6. Budget/Schedule ตั้งค่าถูกต้อง ไม่มีเลขพิมพ์ผิด
7. Media ครบทุก Ratio ที่จำเป็น (1:1, 4:5, 9:16)
8. Primary Text มี Hook ในบรรทัดแรก ไม่ Hard Sell
9. เช็ก Preview ทุก Placement ก่อน Publish
10. มี Baseline Metrics บันทึกไว้เทียบผลลัพธ์ในอนาคต

## สรุปและเชื่อมไปยัง Part ถัดไป

ใน Part นี้เราได้เดินผ่านทุกขั้นตอนของการสร้างแคมเปญ Awareness ตัวแรกแบบละเอียดทุกคลิก ตั้งแต่เปิด Ads Manager, เลือก Objective, ตั้ง Naming Convention, กำหนด Audience/Placement/Budget ที่ระดับ Ad Set, ไปจนถึงเขียน Creative และ Publish รวมถึงสิ่งที่ต้องเช็คหลัง Publish และข้อผิดพลาดที่มือใหม่มักทำ

Awareness คือ Objective ที่ปลอดภัยที่สุดสำหรับฝึกมือ เพราะไม่ได้วัดผลด้วย Conversion ที่ซับซ้อน แต่โครงสร้างการตั้งค่า (Campaign > Ad Set > Ad) ที่คุณเพิ่งฝึกไปนี้ **เหมือนกันทุก Objective** — สิ่งที่เปลี่ยนคือ Performance Goal, Destination, และรายละเอียดเฉพาะทางของแต่ละ Objective

Part ถัดไป (**Part 022: สร้างแคมเปญ Traffic แบบละเอียด**) เราจะเจาะลึก Objective ที่ใช้บ่อยที่สุดในการ "ดึงคนเข้าเว็บไซต์" พร้อมเรียนเรื่อง UTM Parameter, การเลือก Optimization Goal ระหว่าง Link Clicks/Landing Page Views/Conversions, และวิธีป้องกันปัญหา Bot Click/CPC สูงที่เป็นจุดตายของ Traffic Campaign มือใหม่
